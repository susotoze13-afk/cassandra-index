# 01 — Модуль проверки ссылок linkcheck

**Требования:** R03, R06i
**Blocked by:** —
**Зона:** `calc/linkcheck.js`, `tests/`
**Волна:** 1
**Status:** ready

## Что должно заработать

Чистый ESM-модуль без зависимостей, который умеет проверять список URL по
HTTP и отличать рабочие ссылки от битых, с повторными попытками при временных
сбоях. Все функции принимают `fetchImpl` извне — тесты гоняют модуль с
поддельным fetch, без сети.

## Из брифа, дословно

> «Необходимо проверять работоспособность ссылок-источников»

## Разделы спецификации

Решения §3, Швы (единственный новый тестовый шов прогона).

## Критерии приёмки

- [ ] `classify(status)`: 2xx/3xx → 'ok', 404/410 → 'broken', прочее 4xx → 'broken'
- [ ] `checkUrl(url, { fetchImpl, timeoutMs, retries, retryDelayMs })` → `{ url, status, ok, attempts }`; на 429/5xx и таймауте — повтор, не более `retries` попыток
- [ ] `checkSources(items, opts)` → `{ checked, ok, broken: [{url, status, where}] }`, `items` — `{ url, where }`, проверка последовательная
- [ ] Таймаут реализован через AbortController; дефолтные числа — константы наверху модуля
- [ ] `tests/linkcheck.test.js`: полный путь и обрыв, 404, редирект, ретрай на 429/500, исчерпание попыток, таймаут — через поддельный fetchImpl, без сети
- [ ] `node --test tests/linkcheck.test.js` зелёный
