# 01 — Движок и сайт под 46 критериев и методологию 3.0

**Требования:** G02 (часть: критерий в движке/на сайте, кноб методологии)
**Blocked by:** —
**Зона:** `calc/engine.js`, `calc/params.js`, `calc/calc.js`, `js/criteria.js`, `js/i18n.js`, `js/sections/trend.js`, `tests/`, `js/bundle*.js`
**Волна:** 1
**Status:** ready

## Что должно заработать

Движок знает критерий D4.6 «Стресс на финансовых и сырьевых рынках»
(драйвер Д4, esc, ordinal), сайт печатает «46 критериев» и показывает на
тренде точки методологии «3.0», а версия методологии перевыпуска берётся из
`PARAMS.methodology`, а не копируется из прежнего снапшота. Дисковые снапшоты
(`data/`) НЕ пересчитываются и НЕ правятся — они остаются 2.0 до таска 04.

## Из брифа, дословно

> «с учетом новой методологии версии 3.0 и расширенного списка источников для регионов»

## Разделы спецификации

Истории 10, 12; Решения §1 (D4.6), §2 (кноб), §3 (аудит), §4 (тренд); Границы.

## Критерии приёмки

- [ ] `engine.CRITERIA` — 46 записей, `D4.6: { driver: 'D4', dir: 'esc', scale: 'ordinal' }`; `buildDriversCore` маппит D4.6 в Д4 (жёсткие циклы драйверов расширены — проверить вручную, что D4.1–D4.6 все доходят до драйвера)
- [ ] `PARAMS.methodology = '3.0'` — единственный источник версии для перевыпуска; `renderGlobal`/`writeWeek` берут methodology из PARAMS (published по-прежнему из прежнего снапшота); audit: `recalculation_method: 'aggregateDrivers v3.0'`, version_before из снапшота / version_after из PARAMS
- [ ] calc.js при разборе входа печатает warning со списком критериев, чья `regions[]`-атрибуция будет проигнорирована региональной агрегацией (Д2, Д4, Д9 кроме D9.3) — по ADR 0022, молчаливого игнора не должно быть
- [ ] `js/criteria.js` — запись D4.6 (RU/EN название и описание: сырьевые биржи, рынки облигаций и ценных бумаг; раннее реагирование на эскалацию); паритет с engine.CRITERIA
- [ ] Все пользовательские строки с «45 критериями» в js/i18n.js → «46»; сайт одноязычный, строки только через словарь
- [ ] `selectMethodology`/`summaryTextV2` принимают версию по умолчанию '3.0'; подпись «за N недель» считает точки текущей версии; разрыв версий на тренде по-прежнему помечается маркером
- [ ] `node build.js` выполнен, бандлы обновлены; `node --test` зелёный (обновлён пин 45→46 в tests/methodology-criteria.test.js, тесты тренда — под новый дефолт)
- [ ] Дисковые снапшоты data/ не изменены (git status чист по data/)
