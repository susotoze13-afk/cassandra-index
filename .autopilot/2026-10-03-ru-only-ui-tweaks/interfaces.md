# Границы, решённые в спецификации

Новых границ нет: правки внутри существующих модулей. Швы тестов прежние —
чистые модули сайта (`js/i18n.js`, `js/ui.js`, `js/sections/regions.js`,
`js/sections/methodology.js`).

## Правила проекта (для исполнителя)

- Стек: чистый HTML/CSS/JS, **ноль зависимостей**; Node ≥ 18, всё ESM.
  Отсутствующая возможность — не повод ставить пакет: верни BLOCKED.
- Тесты: `node --test` из корня **без аргументов** (форма `node --test tests/`
  падает на Windows/Node 24). Один файл: `node --test tests/<имя>.test.js`.
- После **любой** правки `js/**` — обязателен `node build.js` (бандлы
  `js/bundle.js`/`js/bundle-privacy.js` коммитятся; руками их не править).
- DOM только через `document.createElement` + `textContent` — никакого innerHTML
  со строками. Исключение — существующие шаблоны methodology.js (см. код).
- Цвета — только CSS-токены из `css/styles.css`; a11y: контраст ≥4.5:1,
  touch ≥44px, значения не только цветом, видимый фокус.
- Вся пользовательская строка — через словарь `js/i18n.js` (data-i18n).
- Лексика: без слов из Avoid-списка PRD §11.5, без «на пороге/на грани»,
  без метафоры часов.
- Не трогать: `cassandra-index-prototype.html`, `PRD_Casandra_Index.md`,
  `METHODOLOGY.md`, `data/**`, `calc/**` (этот прогон — только сайт).
- **Не коммитить** — коммит и push делает оркестратор.
- AGENTS.md в корне — полный контекст проекта; читать первым.
