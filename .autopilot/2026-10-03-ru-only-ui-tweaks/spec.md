# Спецификация: UI-правки — индексы регионов, только русский, подписи hero

## Задача

Читатель открывает сайт: в списке регионов виден только Δ без самого индекса;
в методологии висит внутренний блок «Открытые вопросы перед продакшеном»; в шапке
торчит переключатель RU/EN, хотя английская версия не нужна; большое число на
первом экране не подписано; заголовок громоздкий; плашки «Опубликовано» и
«Качество данных» визуально выступают за текст слева.

## Решение

Сайт становится одноязычным (русским), без переключателя языка. Каждая строка
региона в свёрнутом виде показывает индекс региона. Блок открытых вопросов
убран. У большого числа hero — подпись «Мировой индекс». Заголовок —
«Индекс риска глобального военного конфликта». Плашки мета-строки компактнее
и не выступают ниже текста.

## Решения по реализации

- **Одноязычность (R03).** Словарь `en` в `js/i18n.js` удаляется; `t()` и
  инфраструктура `data-i18n` сохраняются (RU остаётся словарём). `resolveLang()`
  в `js/ui.js` возвращает `'ru'` без чтения localStorage/navigator; ключ
  `cassandra.lang` из кода убирается (включая `app.js`, `share.js`, demo).
  Разметка переключателя `.lang-switch` удаляется из `index.html`; CSS
  `.lang-switch`/`.lang-btn` удаляется из `css/styles.css`. `privacy.html`
  тоже одноязычна (свой бандл `bundle-privacy.js` пересобирается тем же
  `node build.js`). ASSUMPTION (full): EN удаляется полностью, без
  сохранения «спящего» словаря.
- **Индекс региона в строке (R01).** В `js/sections/regions.js` в `head`
  добавляется `<span class="region-row-index">` со значением `row.index`
  (перед дельтой); стиль — в `css/styles.css` рядом с остальными
  `.region-*`. Чистый шов `rankedRegions` уже несёт `index` — сигнатуры не
  меняются.
- **Удаление блока открытых вопросов (R02).** Из `js/sections/methodology.js`
  убирается рендер `method.open.*`; из словаря RU — ключи `method.open.*`
  (включая `OPEN_QUESTION_COUNT`, если он только для этого).
- **Подпись hero (R04) и заголовок (R05).** Разметка hero в `index.html`
  (RU-дефолт в HTML — конвенция проекта) + ключи словаря: новый ключ
  `hero.index.label` = «Мировой индекс»; `hero.title` переименован.
  Подзаголовок `hero.subtitle` не трогаем (в брифе не просили).
- **Плашки (R06).** Только CSS: уменьшить вертикальные padding/line-height
  бейджей публикации и качества в hero (селекторы из `css/styles.css`,
  блок «Качество данных (R59–R61)» и мета-плашка «Опубликовано»), чтобы
  высота плашки не превышала высоту строки текста мета-строки. Контраст и
  токены палитры не меняются.
- **Тесты.** Тесты, пинящие EN-словарь/паритет ru-en (i18n.test.js), старый
  заголовок, наличие lang-переключателя или блока open questions —
  актуализируются под новое поведение (конвенция проекта: тесты против
  исходников, не бандла).
- Коммит и push — оркестратор, после приёмки.

## Границы и швы

Изменений границ нет: правки внутри существующих модулей (`js/i18n.js`,
`js/ui.js`, `js/app.js`, `js/share.js`, `js/sections/regions.js`,
`js/sections/methodology.js`, `index.html`, `privacy.html`, `css/styles.css`).
Новых сигнатур нет; `rankedRegions` уже отдаёт `index`. Швы тестов прежние —
чистые модули сайта.
