# 08 — Share-карточка и privacy.html

**Требования:** R17, R49, R80, R81, R82, R83, R84
**Blocked by:** 07
**Зона:** `js/share.js`, `privacy.html`, `index.html` (кнопка «Поделиться» + футер-ссылки и раскрытия)
**Волна:** 8
**Status:** ready

## Что должно заработать

Кнопка «Поделиться» рядом с данными снапшота: canvas 1200×630 → PNG → скачивание;
Web Share API с файловой шарой где поддерживается. Карточка: CASSANDRA INDEX,
«72 / 100 · VERY DANGEROUS», «↑ +6 THIS WEEK», «Your region: Europe · 74 / 100»
(только регион, без города), дата, дисклеймер «Risk assessment based on open data.
Not an official forecast.»; язык карточки = язык интерфейса; вёрстка читаема
в маленьких превью (крупные контрастные элементы, без мелкого текста);
без обратного отсчёта.
Правовые тексты без модалки: дисклеймер §17 дословно рядом с данными и в футере;
в футере — краткое раскрытие IP-обработки дословно: «регион определяется приблизительно
по IP для отображения регионального контекста; адрес не сохраняется и не передаётся
третьим лицам» (RU/EN), сформулированное под будущий бэкенд (в сборке IP не
обрабатывается — часовой пояс не сохраняется и никуда не передаётся); контекстное
раскрытие, никакого блокирующего согласия; «Приватность» в футере → `privacy.html`
с полным текстом политики (цель хранения `cassandra.region`/`cassandra.lang` — R49).
Финальный критерий: все 10 тестов §18 (3-second, 10-second, Trust, Personalization,
Privacy, Trend, Sources, Accessibility, i18n, Performance) выполнимы на собранном сайте —
они станут сценарием слепой приёмки (R84).
