**Status:** ready

## Что должно заработать

Критический режим — функция данных: при global.index ≥81 текущего снапшота рендерится
спокойная плашка «Очень высокий модельный риск / Very high modelled risk» +
текст-дисклеймер дословно из §6.2 (не означает объявления ЧС или начала войны),
раздел «Официальная информация» (только компетентные органы и явно идентифицированные
официальные источники) и список спокойных действий (местные оповещения, инструкции,
базовый запас, связь с близкими). Никогда: сирена, мигание, анимации-«тревоги»,
утверждения о неминуемости, принуждение к действию (§6.4).
Состояния данных (Published/Updating/Delayed/Insufficient data/Model unavailable/
Historical snapshot): каждое — явный локализованный бейдж рядом с датами публикации/
покрытия; Historical snapshot — баннер с датами просматриваемого снапшота; устаревшее
значение никогда не выглядит текущим. Fallback региона: «данные по региону временно
недоступны» при живом глобальном индексе. Model unavailable — битый/отсутствующий
файл данных: понятный экран с кнопкой повтора, не белый экран.
Демо-панель A01: неприметная ссылка «Демо-состояния» в футере открывает панель
(крит-режим / задержка / недостаточно данных / модель недоступна); подмена данных
только в текущей сессии, помечена «демо», в продакшен-потоке не участвует.

## Из брифа, дословно

> «Очень высокий модельный риск / Very high modelled risk … Это модельная оценка на основе последних недельных данных. Она не означает, что официально объявлена чрезвычайная ситуация или что война началась»
> «следите за официальными местными оповещениями; ознакомьтесь с местными инструкциями на случай ЧС; держите базовый запас; договоритесь с близкими о способе связи»

## Разделы спецификации

Истории 16, 17, 18, 28; §6.2–6.4; §10 (состояния); Решение п.10.

## Критерии приёмки

- [ ] Крит-режим включается от данных (≥81), не от кнопки; плашка + дисклеймер §6.2 дословно; раздел «Официальная информация» и список спокойных действий
- [ ] Ничего из §6.4 (сирена/мигание/тревожные анимации/язык неизбежности/принуждение) ни в одном состоянии
- [ ] Все 6 состояний данных имеют локализованный бейдж рядом с датами; Historical snapshot — баннер с датами снапшота; устаревшее значение не выглядит текущим
- [ ] Fallback региона: глобальный индекс жив, персональная строка — «данные по региону временно недоступны» / «regional data is temporarily unavailable»
- [ ] Битый/отсутствующий файл данных → «Model unavailable» с кнопкой повтора, не белый экран
- [ ] Демо-панель: неприметная ссылка в футере; 4 состояния; подмена только в сессии, помечена «демо»; в обычный поток данных не вмешивается
- [ ] Всё локализуется; состояния читаются скринридером (бейджи не только цветом)
