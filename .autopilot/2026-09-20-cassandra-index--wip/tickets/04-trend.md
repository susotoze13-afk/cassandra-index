# 04 — Тренд за 12 недель

**Требования:** R35, R36, R37, R38, R39, R40
**Blocked by:** 03
**Зона:** `js/sections/trend.js`, `index.html` (секция «Тренд»), `js/render.js` (подключение секции)
**Волна:** 4
**Status:** ready

## Что должно заработать

Интерактивный график тренда за 12 недель, целиком инлайн-SVG из данных снапшота.
Подпись к секции: текущее значение, значение неделю назад, направление, короткий
нарративный summary. 12 точек с датами; каждая — фокусируемый элемент
(tabindex=0, role=button, aria-label со значением и датой). Hover / фокус / tap —
точка растёт, tooltip: «N / 100» (mono 15/600, доминирует) + дата (mono 11, muted,
локальный формат); tooltip aria-hidden, позиция зажата по X внутри контейнера;
на тач — автоматическое скрытие через 3.5 с. Линия 2px --accent, область —
градиент rgba(88,166,255,.30) → 0, направляющие --border-soft 1px, ось подписана
30/60/90 mono 10px, последняя точка крупнее с обводкой --surface.

## Из брифа, дословно

> «Компактный интерактивный тренд за 12 недель … текущее значение; значение неделю назад; направление; короткий нарративный summary; все 12 точек данных с датами»
> «При наведении курсора на точку: точка визуально увеличивается; появляется tooltip … N / 100, mono, 15 px, вес 600; дата … mono, 11 px, --text-muted»

## Разделы спецификации

История 13; Решение п.8 (инлайн-SVG); §19.25 (aria-label точек вместо aria-live — решение сборки).

## Критерии приёмки

- [ ] 12 точек с датами из снапшота; подпись: текущее, неделю назад, направление, summary — всё локализуется
- [ ] Каждая точка: tabindex=0, role=button, aria-label «значение, дата» на языке интерфейса
- [ ] Hover/фокус/tap: точка растёт, tooltip «N / 100» mono 15/600 + дата mono 11 muted; tooltip не выходит за контейнер по X; tap скрывает tooltip через 3.5 с
- [ ] Визуал: линия 2px --accent, градиентная область, сетка 30/60/90 mono 10px, последняя точка крупнее с обводкой --surface
- [ ] График проходит с клавиатуры (фокус на каждой точке видимый), prefers-reduced-motion уважается
- [ ] Работает с `file://`; никаких библиотек визуализации
