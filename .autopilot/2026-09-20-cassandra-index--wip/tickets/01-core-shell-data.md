**Требования:** R01, R09, R26, R46, R47, R63, R63.1, R64, R65, R73, R76, R77

**Зона:** `css/`, `js/data.js`, `js/i18n.js`, `js/risk.js`, `js/region.js`, `js/render.js` (скелет dispatch), `js/app.js` (скелет init), `data/`, `tests/`
**Волна:** 1
**Status:** ready

## Что должно заработать

Фундамент, на который встают все остальные таски. Сайт открывается (`file://` и
статический хостинг) и показывает каркас index.html с нормативными CSS-токенами §14.4.
Демо-данные лежат в `data/<дата>/*.js` (≥6 недель истории + указатель latest) и
попадают в `window.CI_DATA` через script-теги — без fetch. Чистые модули
`i18n` (словари RU/EN, плюрализация, даты), `risk` (шкала §10 → статус/тон),
`region` (справочник 6 регионов + ~30 городов, детект по IANA-часовому поясу,
выбор с явным persist) и `data` (latest/week/listWeeks/validate) покрыты тестами
`node --test` и зелёные. `render.js` — скелет dispatch (`renderAll` по секциям),
`app.js` — скелет `init()`. Битый или отсутствующий файл снапшота даёт
диагностируемое состояние «Model unavailable» в данных, а не падение.

## Критерии приёмки

- [ ] `index.html` + `css/styles.css` открываются с `file://`; все токены §14.4 определены и используются
- [ ] `data/` содержит ≥6 недель снапшотов (последняя — global 72, Δ ↑+6, как в прототипе-референсе) + `data/latest.js`; новая неделя добавляется каталогом + правкой указателя, без правки кода
- [ ] Снапшоты подключены `<script src>`, данные в `window.CI_DATA`; fetch нет нигде
- [ ] `risk.status` возвращает правильный ключ §10 для границ всех шести диапазонов (0–20…97–100); `tone`/`deltaTone` маппят на токены палитры (рост → --state-very, снижение → --state-calm, ноль → --text-secondary)
- [ ] `region.detect` маппит IANA-префиксы часовых поясов в 6 регионов; неизвестный пояс → null; `choose` пишет в localStorage только при явном persist; `search` находит регион по ~30 городам
- [ ] `i18n.t/plural/date`: плюрализация RU 1/2–4/5+ («1 источник / 2 источника / 5 источников»); даты 13 сентября 2026 / 13 Sep, 2026 и 13.09 / Sep 13 через Intl
- [ ] `data.validate` отклоняет снапшот без обязательных полей; битый файл → состояние «Model unavailable» с кнопкой повтора (интерфейс состояния — в таске 06, здесь — данные и событие)
- [ ] `node --test tests/` — зелёные тесты на швах: i18n, risk, region.search/detect, data.validate
- [ ] `js/render.js` — `renderAll(appState)` с dispatch по именам секций; `js/app.js` — `init()`; оба — рабочие скелеты, которые таск 02 наполняет
