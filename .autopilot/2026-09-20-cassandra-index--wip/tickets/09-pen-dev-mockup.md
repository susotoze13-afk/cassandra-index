## Что должно заработать

Файл `design/cassandra-index.pen` — дизайн-макет сайта Cassandra Index в формате pen.dev
(текстовый JSON, version 2.6). Открывается в pen.dev: VS Code-расширение highagency.pencildev
(Recent Files → открыть файл) или приложение pen.dev.

Экранные фреймы (top-level в `document`, `clip: true`), растущие вправо-вниз:

1. **Desktop hero, 1440×900** — sticky header (бренд Cassandra Index, навигация
   Overview / Regions / Trend / Methodology, переключатель RU/EN), заголовок
   «Насколько близко мир подошёл к глобальному военному конфликту?», доминирующее число
   **72** / 100 со статусом «Опасно» и дельтой «↑ +6 за неделю», даты «Последняя публикация:
   15 сентября 2026» и «Данные по: 13 сентября 2026» (визуально разнесены), персональная
   карточка региона: левая цветная полоса по состоянию, «Амстердам» ~20px/600, «Европа · 74»
   приглушённо с инлайн-кнопкой «изменить», индекс региона + словесный статус + недельное изменение.
2. **Desktop sections, 1440** — «Что изменилось»: три карточки драйверов (лейбл, наблюдение,
   вклад высокий/средний/низкий, уверенность + причина снижения, кнопка --accent «3 источника»
   с chevron); дополнительные измерения словами без процентов («Прямое военное столкновение —
   Высокий»); «Тренд за 12 недель»: линия --accent 2px с точками, подписанная ось 30/60/90,
   текущее значение и значение неделю назад.
3. **Desktop regions, 1440** — «Где риск изменился сильше всего»: ranked-строки регионов
   (название, индекс, Δ, статус), семантический список (не только «карта»); футер: примечание
   «экспериментальная оценка… не официальный прогноз», ссылка «Приватность», переключатель языка.
4. **Mobile hero, 360×640** — тот же первый экран: регион виден без скролла, header ≤88px.
