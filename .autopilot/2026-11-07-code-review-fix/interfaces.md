# Интерфейсы и границы — прогон 2026-11-07-code-review-fix

## Правила проекта (из carried.md «Договорились» — дословно, обязательны)

- Все grilling-решения Q1–Q17 и «Начинай» = разрешение реализации — держит
  ADR 0069 (статус «реализовано»); повторно не обсуждаются.
- `Δ_region` — внутренняя мера, наружу не публикуется — ADR 0072 и сторож
  `tests/regional-deviation.test.js`.
- «13 недель» в Q9 — счётная ошибка, верная цепочка 08-30…11-01 = 10 недель
  (пин глобальных чисел — на все 10, демо-недели 1.0 не трогаются).
- Выпуски блога 10-25/11-01 остаются methodology 3.0 — вне рамок 4.0
  (переиздан только 10-18, ADR 0070).

## Границы, решённые в спецификации

- **Ревью не пишет код.** Ревьюер (субагент) читает дифф и возвращает
  классифицированный список находок. Оркестратор разводит их по классам.
- **Исправления — исполнителями.** Каждая находка «исправить сейчас» —
  отдельный тикет-ремонт; исполнитель правит только названные файлы,
  git не трогает (коммит — за оркестратором).
- **Правка `js/**` ⇒ `node build.js`** в том же тикете; бандлы коммитятся
  вместе с исходниками.
- **Производные файлы** (`data/public/**`, `changelog.html`, `digest.html`,
  `data/analysis.js`) не правятся руками ни ревьюером, ни исполнителем —
  только CLI пересборки; если правка их меняет, это явно указано в тикете.
- **Пины тестов** (глобальные числа 10 недель, разброс регионов 11-01,
  sensitivity) — не «недостатки кода»: ломать их при ремонте нельзя,
  меняются только при пересчёте данных.
- **Чужие файлы** (staged `docs/articles/vc-binance-*` параллельной сессии)
  не читаются, не правятся, не коммитятся.
- **Чистые модули сохраняются:** исправления не добавляют диск/сеть/DOM в
  чистые функции; швы для тестов — инъекция как сейчас.
