## Что должно заработать

Для недели 02.11–08.11.2026 собраны реальные источники по десяти критериям
Д1.1–Д1.6 (территориальные конфликты и эскалация) и Д5.1–Д5.4 (военные
сигналы) и записан фрагмент входа `part-d1-d5.json`. Каждый покрытый критерий
подтверждён минимум двумя независимыми кластерами (или одним primary/OSINT),
каждый слепой — с причиной; у покрытых критериев заполнена региональная
атрибуция `regions[]` (только Д1/Д5 — допустимые драйверы).

## Критерии приёмки

- [ ] `calc/input/drafts/2026-11-08/part-d1-d5.json` существует, валидный JSON:
      `week` = "2026-11-08", в `criteria` ровно 10 ключей D1.1–D1.6 и D5.1–D5.4
      (объект или `null`), есть `sources`, `blindReasons`, `driverConfidence`
- [ ] каждый покрытый критерий: ≥2 разных `cluster_id` среди источников
      **или** ≥1 источник `source_type` primary|OSINT
- [ ] у каждого `null` есть причина в `blindReasons`
- [ ] каждая запись `sources[]` — полный R55 (id, title.ru/en, domain, url,
      publication_date в 02.11–08.11.2026, accessed_date 2026-11-08,
      source_type, cluster_id, state_affiliated), без дублей `id`
- [ ] каждый URL критерия есть в `sources[].url`; каждый URL проверен curl —
      ни одного 404/410 (blocked 401/403/406 допустим); в ответе — сводка проверки
- [ ] `regions[]` — только на Д1/Д5, id из 12 таксономии v2, без дублей
