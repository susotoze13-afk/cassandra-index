# Спецификация: региональные гипотетики §7 — порог покрытия (вариант E)

## Задача

Читатель видит на неделе 2026-10-18 russia-belarus 56 и ukraine-moldova 58 при
глобальном 64 — регионы с активными боевыми действиями стоят ниже всех, и ниже
регионов без войны. Причина — не данные: региональные сигналы учтены, но
гипотетика `iWith` обнуляется порогом покрытия 50 %, унаследованным от
глобального §4.2. Регион получает штраф −8 и −7 п.п. под глобальный фон.

## Решение

Региональные гипотетики `iWith`/`iWithout` считаются по правилу «драйвер покрыт,
если в подмножестве есть хотя бы один его покрытый критерий» (порог 1e-9 вместо
0.5). Драйверы без сигналов региона по-прежнему слепые — фантомных драйверов нет.
Глобальный индекс, q, состояния, публикация и чувствительность не меняются.

**Охват истории — вопрос пользователю.** Бриф рекомендует пересчитать цепочку
08-30…10-18 (перезапись опубликованных значений), но задача прямо относит выбор
версии и охвата к Methodology Editor, а перезапись опубликованных данных — действие
над опубликованной историей. Поэтому код и тесты делаются безусловно, а пересчёт
запускается только по слову пользователя (вопрос задан через `ask action`). Если
ответа нет — остаётся forward-only с гейтом `regionHypothesisFrom = '2026-10-25'`
и опубликованная история не трогается.

## Решения по реализации

- **Точка правки** — `calc/engine.js`, `regionalSignals`: две гипотетики получают
  объект параметров с подменённым `coverageThreshold`. Больше ничего не меняется.
- **Новый чистый шов** — `regionalHypothesisParams(params, week)` в `engine.js`:
  возвращает `params` или `{ ...params, coverageThreshold: regionHypothesisThreshold }`.
  Гейт: `week` — строка и `week < regionHypothesisFrom` → без подмены; иначе подмена.
  Пустая/отсутствующая дата гейта → подмена всегда (прецедент `independenceGateFrom`).
- **Сигнатура** — `regionalSignals(criteria, regionIds, params, week)`: четвёртый
  аргумент опциональный, production-вызов один — `calc/week-step.js:125` передаёт
  `week` из `computeWeek`.
- **Параметры** — `calc/params.js`: `regionHypothesisThreshold: 1e-9`,
  `regionHypothesisFrom: '2026-10-25'` (при выборе пересчёта — `'2026-08-30'`,
  первая пересчитываемая неделя цепочки).
- **Дата сравнивается строкой** по ISO `YYYY-MM-DD`, как в `taxonomyForWeek` и
  `validateSourceIndependence`.
- **Публичный контракт не трогаем**: `methodology.json` не получает новых полей —
  это отдельное решение (см. «Вне рамок»).
- **Пересчёт (если выбран)**: `node calc/calc.js --write 2026-08-30 … 2026-10-18`
  (нужна сеть: linkcheck-ворота R03) → `node calc/public-export.js --write` →
  `node calc/digest-export.js --write` → при необходимости
  `node calc/migrate-week-combined.js` → пины тестов → `node --test`.
  `PARAMS.methodology` не растёт (прецедент recalc-0019).
- **`node build.js` не нужен**: правка только `calc/**` и `docs/**`.
- **Никаких зависимостей**, только stdlib.
