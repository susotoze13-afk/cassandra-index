# Спецификация: цитаты источников — хранение, показ, выкат

## Задача

Индекс говорит «уровень риска вырос», а проверить это можно только перейдя по ссылке
и перечитав статью целиком. Читателю нужен тот самый фрагмент текста, на котором
построен сигнал: не пересказ, не заголовок, а дословная цитата — иначе «открытые данные»
остаются обещанием, а не проверяемым фактом. Сейчас источники лежат в данных без цитат:
у пилота Jev цитаты есть в черновиках, но публикация их теряет.

## Решение

**Что продолжается.** «Продолжи» — продолжение работы после сданной сборки
`2026-10-18-severity-calibration`: в её `PROGRESS.md` осталось три пункта, пользователь
взял два (`events[]` в якорях и ADR 0039) и оставил третий вне рамок («Без k×severity»).
Оба взятых — в §Решение 6.

1. **Хранение.** У записи источника появляется опциональное поле `quotes` — список
   `{criterion, text}`: какая цитата какой критерий подпирает. Поле живёт во входе недели
   (`calc/input/<неделя>.json`), доезжает до опубликованного снапшота `data/<неделя>/sources.js`
   и до `week.js` без отдельного кода публикации — генератор переносит запись источника
   целиком. Источники без цитат остаются валидными (десять недель без поля).
2. **Проверяемость.** Цитата принимается только дословная: перед записью недели она ищется
   в корпусе текста этого источника (`calc/input/drafts/texts-<неделя>/<id>.txt`) той же
   нормализацией, что у пилота Jev. Нет корпуса или фрагмент не найден — запись отклоняется
   с указанием источника и критерия; цитата, которую нельзя проверить, не публикуется.
3. **Показ.** В аккордеоне источников под записью появляется цитата с подписью «Цитата»
   и указанием критерия; в витрине доверия — строка «С цитатой: N из M». У источников
   без цитат ничего не появляется и вёрстка не меняется.
4. **Заполнение.** Цитаты переносятся задним числом для двух недель, где есть корпус
   и черновики: 09-20 (`eventsDetail[].quote` вместе с `source`) и 09-27 (цитата критерия,
   если у критерия ровно один источник). Только те фрагменты, что находятся в корпусе
   дословно. Остальные десять недель остаются без цитат — выдумывать нечего.
   *Почему не все двенадцать:* корпус текстов существует только у двух недель пилота Jev;
   цитату, которую нельзя проверить дословно, спецификация запрещает (п. 2), а сочинить
   её — значит выдать пересказ за источник. Требование «хранение источников с цитатами»
   выполнено механизмом и публикацией: поле есть у всех недель, заполнено там, где есть
   чем.
5. **Выкат.** Изменения уходят в `master`, `deploy.yml` публикует сайт, живой
   `cassindex.ru` проверяется после выката.
6. **Доработки прошлой сборки.** (а) `events[]` добавляются в якоря калибровки только там,
   где значение воспроизводится точно — 131 критерий из 387; значения якорей, k и числа
   опубликованных недель не сдвигаются. Не получают `events` — критерии со значением `0`
   (пустой список событиями не считается), `0.33` и `0.67` (суммой весов `0.2/0.5/1.0/2.0`
   не представляются) и все ordinal-критерии (Д4/esc, D4.6). (б) ADR 0039 фиксирует два
   решения severity-прогона: метрика выбора `sens` и вынос шага недели в `calc/week-step.js`.

## Решения по реализации

- **Поле — `quotes`, не `quote`.** Один источник закрывает несколько критериев, у каждого
  свой фрагмент; плоское `quote` смешало бы их. Запись: `{criterion, text}`.
- **Публикация не требует кода.** `writeWeek` пишет `input.sources` в `sources.js` verbatim
  (`calc/calc.js:586-610`), `renderWeekCombined` склеивает части — поле доезжает само.
- **Проверка — новый чистый модуль `calc/quotes.js`** поверх `normalizeText`/`quoteFound`
  из `calc/classify.js` (пилот Jev уже нормализует так же). Шов тестов — без сети и без DOM.
- **Ворота — до диска, рядом с `validateInputSources`.** Причина отказа видна редактору
  до записи, диск не тронут; это та же политика, что у linkcheck и контракта.
- **Корпус обязателен для цитаты.** Нет `texts-<неделя>/<id>.txt` — цитата не принимается:
  «проверяемая» иначе значит «написанная по памяти».
- **Лимиты.** `text` 1..1200 символов, не больше 12 цитат на источник: публикация не должна
  раздуваться (71 источник × несколько цитат уже сейчас даёт 1000+ строк `sources.js`).
- **Сайт знает поле как опциональное.** `isSource` проверяет форму, если поле есть;
  отсутствие — норма (10 недель из 12).
- **Цитата под источником в аккордеоне** — через поиск по `url` в `snapshot.sources`:
  источники драйверов и регионов несут сокращённую схему без `id`.
- **Заднее заполнение — только каноническим путём**: `node calc/calc.js --write 2026-09-20 2026-09-27`
  после правки входов; числа недель обязаны остаться прежними (пины `tests/data.test.js`).
- **Якоря: `events` вместо `value` только при точном равенстве** `min(1, Σsev/5) === value`;
  `capCount = 5`, веса `PARAMS.severityValues`. Несчётные (ordinal, D4.6) не трогаются.
- **ADR 0039** — формат 0037/0038, два решения: `sens` как метрика выбора и `calc/week-step.js`.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Скалярная/ковариационная калибровка k×severity | пользователь: «Без k×severity» — после D4.6 почти независимы |
| Цитаты для десяти недель без корпуса | корпуса нет; выдуманная цитата хуже отсутствия |
| Поиск/фильтр по цитатам на сайте | не просили; список источников читается глазами |
| Цитаты во вкладке «История и источники» | секция скрыта (ADR/пин `tests/page-structure.test.js`) |
| Смена чисел опубликованных недель | пользователь: «Без сдвига чисел» |
