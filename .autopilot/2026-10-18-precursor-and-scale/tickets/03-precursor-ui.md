**Требования:** R04, R09, R10, R11, R21i
**Зависит от:** 02
**Зона:** `js/sections/precursor.js` · `js/render.js` · `js/i18n.js` · `index.html` · `css/styles.css` · `js/bundle.js` · `js/bundle-privacy.js` · `tests/precursor-ui.test.js` · `tests/trust.test.js`
**Волна:** 3
**Ревью:** да — публичная поверхность
**Модель:** обычная

## Что должно заработать

На сайте между hero и витриной доверия появляется блок «Косвенные предвестники (Д9)»:
целый процент, «N сигналящих подгрупп из 8» и дисклеймер §4.3.6. Блок виден только у
опубликованной недели с полем `precursor`; на неделях без поля его нет вовсе. В секции
«Методология» — 3–4 предложения про то, что шкала порядковая с прокалиброванными границами
и что расстояние между числами не измерено.

## Из брифа, дословно

> «блок «Косвенные предвестники (Д9)» между hero и витриной доверия; скрыт, если неделя не
> published или D9 = null; при nSub = 0 — 0 % с пометкой «сигналов нет»»

> «round(s9·100) %, подпись «доля сигналов Д9, не сравнимо с индексом», «N сигналящих
> подгрупп из 8», дисклеймер §4.3.6»

> «3–4 предложения в секции «Методология» (через js/i18n.js + node build.js)»

## Разделы спецификации

Истории 7, 8, 11–13, 16–20, 33; «Решение» пункты «Сайт» и «Тексты»; `interfaces.md` —
`js/sections/precursor.js`, `js/render.js`, `js/i18n.js`.

## Критерии приёмки

- [ ] `js/sections/precursor.js` экспортирует `precursorFacts(snapshot)` и
      `PRECURSOR_SUBGROUPS = 8`; `null` при отсутствии `global`, поля, при
      `dataState !== 'published'` и при битой форме
- [ ] `PRECURSOR_SUBGROUPS` равен `D9_SUBGROUPS.length` из `calc/engine.js` (тест-паритет)
- [ ] `precursor` в `SECTIONS` между `hero` и `trust`; хост `[data-section="precursor"]`
      стоит в `index.html` между hero и `.trust-section`
- [ ] При `value = 0, signaling = 0` блок показывает «0 %» и пометку «сигналов нет»;
      при `signaling = 0`, `value > 0` этого не происходит
- [ ] В блоке есть подпись «доля сигналов Д9, не сравнимо с индексом» и дисклеймер §4.3.6;
      нет `risk.tone`, классов `--state-*`, нет слова «вероятность»
- [ ] В секции «Методология» появился абзац про шкалу: «порядковая», «границы состояний
      прокалиброваны», «расстояние — не измеренная величина»; без «перцентиль»
- [ ] Новые ключи `precursor.*` и `method.scale.*` есть в `js/i18n.js`; тест assert-ит
      наличие ключей, плейсхолдеры `{value}`/`{n}` и отсутствие цифр в `precursor.note`
- [ ] `node build.js` пересобрал оба бандла; `node --test` зелёный
- [ ] 320 px: блок в одну колонку, без горизонтального скролла (проверка — в тесте разметки
      или в отчёте исполнителя)
