# Спецификация: обновление статьи Habr под методологию 3.0

## Задача

Статья «Индекс Кассандры» для Habr описывает проект по состоянию на методологию 2.0:
в ней индекс 55, 45 критериев и предварительное обещание ввести рыночный критерий «к методологии 3.0».
С тех пор проект перевыпущен: введена **методология 3.0**, добавлен **46-й критерий D4.6 (стресс рынков)**,
вся цепочка пересчитана (индекс 10-11 = 56), региональная атрибуция задействована данными,
метод отбора источников дополнился метрикой чувствительности с фактическими числами. Статья,
опубликуй её как есть, содержала бы неверные числа и устаревшее описание метода.
Задача — привести статью и её производные в соответствие с текущим состоянием репозитория.

## Решение

Обновляются:
1. статья-источник `docs/articles/habr-idea-d.md` (тело + рабочие заметки/факт-чек);
2. производные `docs/articles/habr-post-final.md` и `.plain.txt` (регенерируются из источника);
3. пакет публикации `docs/articles/habr-publish-package.md` (числа в подписях/alt, заголовок);
4. скриншоты `docs/articles/img/*.png` — перерисованы под текущее состояние сайта (3.0).

## Решения по реализации

**Источники фактов (не выдумывать):**
- `data/<week>/global.js` — index/delta/q/coverage/sensitivity/methodology;
- `calc/engine.js` (`CRITERIA` 46, D4.6 — Д4/esc/ordinal), `calc/params.js` (`methodology='3.0'`, `k=1.95`);
- `docs/calibration-journal.md` — 10 якорей (7 select + 3 verify), k подтверждён;
- ADR 0021 (рыночный критерий → 3.0), 0023–0027 (регионы/перевыпуск);
- `node --test` — 38 файлов / 359 проверок.

**Правки в теле `habr-idea-d.md`:**
1. «Свежая неделя (11 октября 2026): 55, +10 (45)» → «56, +10 (46)».
2. «9 драйверов, 45 критериев» → 46; в подписях/alt картинок — 46.
3. «методология 2.0» → «3.0»; «тренд — только по версии 2.0» → 3.0.
4. Чувствительность: «для недели 4 октября — 11,8 пункта … для 11 октября — ноль» → «5,4 пункта
   (выше порога 5 — неделя помечена) … ноль».
5. Абзац про «подан критерий состояния фондового рынка … к методологии 3.0 — отдельным
   прогоном … работает на 45 критериях» → **переписать как реализованное**: методология 3.0,
   D4.6 (стресс рынков) введён, цепочка перевыпущена, 46 критериев.
6. Регионы: механизм атрибуции больше не «задел» — недели смешанные (регионы с сигналами
   и слепые), у слепых пометка «Индекс отражает глобальный фон»; слепых 4/5/4/3/3/2/2 из 6.
7. Тесты: «36 тест-файлов / 345» → 38 / 359.
8. Калибровка: «10 якорных профилях (6 отборочных + 4 проверочных)» → «(7 отборочных + 3 проверочных)».
9. Jev: «по 45 критериям» → «по критериям D1…D9 (46)».
10. Раздел о целостности/отборе источников («Как гарантируется целостность») — явная проверка
    и правка под текущее состояние: ворота независимости (≥2 кластеров ИЛИ ≥1 primary|OSINT,
    действуют с 11 октября), метрика чувствительности (порог 5 п.п., фактические числа),
    ядро источников (9 доменов A/B/C/F), red team-чек-лист (7 вопросов), проверка ссылок
    и контракт данных (без изменений по механике); вход расширен 12 региональными
    R55-записями по 7 неделям — упомянуть как часть метода отбора.

**Рабочие заметки / факт-чек:** обновить перечень фактов (числа, D4.6, 3.0, 38/359, якоря, ADR 0021/0023–0027).

**Пакет:** заголовок «45 критериев…» → «46 критериев…»; подписи картинок и alt с 55/45 → 56/46;
в риски/чеклист — без изменений по сути.

**Скриншоты:** перерисовать 01-hero, 02-trend, 03-drivers, 04-criteria, 05-criteria-d1 против
`file://` текущего `index.html` (в `data/` уже 3.0) headless-Chrome через CDP. 06-draft-specimen
