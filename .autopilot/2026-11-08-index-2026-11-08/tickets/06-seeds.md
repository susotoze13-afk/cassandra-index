## Что должно заработать

Для недели `2026-11-08` созданы редакционные сиды, без которых генератор
отклонит запись: `global.js` с `published`, `trend.js` с ровно 12 точками,
`drivers.js` с тремя историями драйверов по свежим событиям недели и 12 файлов
`region-*.js` по два драйвера на регион. Источники сидов — verbatim-записи по
`id` из входа недели (иначе linkcheck пойдёт проверять лишние URL).

- [ ] 15 файлов существуют и исполняются как classic script
      (`window.CI_DATA`): `global`, `trend`, `drivers` + 12 `region-<id>`
- [ ] `global.js`: `published` = "2026-11-08", `regions_taxonomy` = "2.0"
- [ ] `trend.js`: ровно 12 точек, даты 2026-08-23…2026-11-08 подряд по неделям

      `contribution`/`confidence` из high|medium|low, 2–5 источников; все `id`
      источников существуют во входе недели
- [ ] 12 файлов `region-*.js`: по 2 драйвера, у каждого ru+en, `confidence`;
      региональные источники — из входа недели
- [ ] `node calc/calc.js 2026-11-08` по-прежнему завершается кодом 0 (сиды не
      ломают контракт снапшота)
