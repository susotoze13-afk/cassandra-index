# 03 — Оверлей атрибуции для недели 2026-10-25

**Требования:** R01, R05, R09i
**Зависит от:** 02
**Зона:** `calc/input/countries/` · `data/2026-10-25/` · `calc/classify.js` (только чтение)
**Волна:** 3
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

По входу недели 2026-10-25 собран редакционный оверлей `calc/input/countries/2026-10-25.json`:
критерии, относящиеся к России и/или Украине, с факт-основанием и ссылками только
на источники, реально присутствующие во входе недели. По оверлею записана часть
`data/2026-10-25/countries.js` и пересобран `week.js` (аддитивно: остальные части
недели — собственность параллельной сессии — не перезаписывались). Опубликованы
индексы RU и UA с покрытием и сигналами.

> «по России и Ураине с ближайшей недели»

## Критерии приёмки

- [ ] Оверлей проходит `validateCountryOverlay` без ошибок: только критерии из 46, все покрыты, `countries` ⊆ {RU, UA}, без дублей id, каждая запись с непустым `basis` и ≥1 url из `calc/input/2026-10-25.json`
- [ ] Атрибуция опирается только на факты из источников недели (учения, санкции, удары, дипломатия — по месту события); критерии с `intersection: true` и неподходящих драйверов (Д2/Д4/Д9-кроме-D9.3) в оверлей не входят
- [ ] Каждая из двух стран в атрибуции имеет источники из ≥2 кластеров whitelist
- [ ] `node calc/calc.js 2026-10-25` (печать, без --write) показывает строку стран с опубликованными RU/UA
- [ ] Записаны `data/2026-10-25/countries.js` и `data/2026-10-25/week.js`; `git diff` по остальным частям недели пуст
- [ ] Значения RU/UA отличаются от своих регионов (russia-belarus/ukraine-moldova), если атрибуция не тождественна региональной
