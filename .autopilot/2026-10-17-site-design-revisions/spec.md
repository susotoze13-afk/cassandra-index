# Спецификация: Дизайн сайта с учётом новых правок (панель доверия, покрытие, share)

## Задача

Человек открывает сайт индекса после выката новых блоков (витрина доверия, поле
покрытия, share-карточка с уровнем и дельтой). Новые элементы технически работают,
но появились на странице быстрее, чем был выверен их визуальный стык с остальным
дизайном: посетитель должен видеть единый сайт, а не «старый дизайн + новый блок».

## Решение

Витрина доверия (строка-факт и раскрытие деталей), share-карточка и всё, что
появилось в коммитах 7f98293/37ff4e0/53fdaa3, визуально вписано в существующий
дизайн-системный язык сайта: те же токены палитры и радиусов, тот же ритм секций,
те же состояния интерактива. Изменения — только `css/styles.css` и (минимально)
`index.html`; стиль сайта в целом не пересматривается. Выкат не производится:
коммит локально, пуш — за пользователем (его слова: «Только коммит локально»).

## Решения по реализации

- **Правится только слой представления**: `css/styles.css` (основное), `index.html`
  (только если шлифовка требует разметки). `js/**` — только если без этого нельзя
  выполнить историю 2–3, и тогда обязателен `node build.js` (бандл коммитится,
  конвенция проекта). `calc/`, `data/`, `METHODOLOGY.md`, `design/cassandra-index.pen`
  не трогаются (pen пинится tests/pen.test.js по версии).
- **Новая палитра не вводится**: только существующие CSS-токены `css/styles.css`
  (`--surface`, `--border`, `--text`, `--text-secondary`, `--accent-line`,
  `--state-*` для тона риска). Цвет — только через токены, конвенция проекта.
- **Строка-факт остаётся компактной**: sr-only заголовок `trust-title` —
  осознанное решение предыдущего прогона (компактная витрина без видимого H2),
  не отменяем. Шлифуется форма (переносы, отступы, состояния), не концепция.
- **Проверка — скриншотами**: headless Chrome (в среде доступен, опыт прошлых
  прогонов) на 1280px и 360px, до/после для ревьюера. Автотестов на CSS в проекте
  нет и не добавляется — приёмка визуальная + зелёный `node --test`.
- **Ограничение дифа**: правки поверх текущего HEAD (53fdaa3 + 7fe9228 уже
  запушены). Никаких пересборок данных и недель.

## Границы и швы

Единая зона работы — фронт-слой сайта. Больше одного модуля не появляется,
публичных сигнатур нет; чистые швы (`trustFacts`, `factsLine`, `showSensitivity`
в js/sections/trust.js) не меняются — дизайн не трогает логику и её тесты.

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| фронт-слой (`css/styles.css` + `index.html`) | визуальная интеграция новых блоков | ничего — нет программных потребителей | всё внутреннее оформление |

Швы для тестов: существующие (`tests/trust.test.js` и пр.) — не трогаются, новых нет.
Поведенческая проверка этого прогона: зелёный `node --test` (регрессия) +
скриншотная визуальная приёмка (процесс, не код).
