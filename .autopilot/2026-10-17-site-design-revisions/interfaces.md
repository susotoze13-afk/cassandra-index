# Интерфейсы: границы и правила проекта

## Границы, решённые в спецификации

Единая зона работы — фронт-слой сайта (представление). Публичных сигнатур нет,
чистые швы логики (`trustFacts`, `factsLine`, `showSensitivity` в js/sections/trust.js)
не меняются — дизайн не трогает логику и её тесты.

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| фронт-слой (`css/styles.css` + `index.html`) | визуальная интеграция новых блоков (витрина доверия, покрытие, share) | ничего — программных потребителей нет | всё внутреннее оформление |

Швы для тестов: существующие (tests/trust.test.js и пр.) не трогаются, новых нет.
Регрессия — `node --test` (зелёный), приёмка — скриншоты headless Chrome 1280px/360px.

## Правила проекта (нельзя вывести из кода за один взгляд)

- Стек: чистый HTML/CSS/JS, **ноль зависимостей**; Node ≥ 18, всё ESM (кроме CommonJS build.js). Любой импорт npm/CDN — ошибка.
- **Не трогать:** `calc/`, `data/` (кроме чтения снапшотов для скриншотов), `METHODOLOGY.md`, `PRD_Casandra_Index.md`, `cassandra-index-prototype.html`, `design/cassandra-index.pen` (пин tests/pen.test.js).
- Цвета — только CSS-токены из `css/styles.css` (`--surface`, `--border`, `--text`, `--text-secondary`, `--accent-line`, `--state-*`). Новая палитра не вводится.
- Вся пользовательская строка — только через словарь `js/i18n.js` (data-i18n и т.п.); DOM — только `createElement` + `textContent`, никакого innerHTML со строками.
- a11y-стандарты сайта: видимый фокус 2px #58A6FF, контраст ≥4.5:1, тач ≥44px, reflow 320px, prefers-reduced-motion, значения не цветом.
- Лексика: без слов из Avoid-списка PRD §11.5, без «на пороге/на грани» и метафоры часов.
- После ЛЮБОЙ правки `js/**` — обязателен `node build.js` (бандлы `js/bundle*.js` коммитятся; страницы грузят бандлы, не ES-модули). Правка только css/index.html бандл не требует.
- Тесты: `node --test` — из корня, без аргументов (форма `node --test tests/` падает на Windows/Node 24). Текущий зелёный: 446 passed / 0 fail.
- **Коммит и пуш:** коммит локально — можно (решение пользователя), **пуш запрещён** (пуш в master триггерит прод-деплой; пуш — за пользователем). Исполнитель-агент коммит не делает — коммит остаётся за оркестратором.
- Отсутствующая возможность/инструмент — вернуть `BLOCKED` с описанием, не ставить пакеты.
- Скриншоты: headless Chrome в среде доступен (опыт прошлых прогонов), сайт работает с `file://` (бандлы подключены в index.html).
