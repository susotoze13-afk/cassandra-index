# Спецификация: расчёт индекса Кассандры за неделю 12.10–18.10.2026

## Задача

Владелец сервиса ставит еженедельную задачу: посчитать и опубликовать индекс
риска глобального конфликта за новую неделю — с 12.10 по 18.10.2026. Публичный
сайт (cassindex.ru) показывает последнюю неделю; без нового расчёта читатели
видят устаревшие данные от 11.10.

## Решение

Неделя `2026-10-18` рассчитана штатным пайплайном и опубликована: вход
`calc/input/2026-10-18.json` собран из реально существующих открытых источников
окна 12.10–18.10.2026, расчёт прошёл ворота ссылок и контракта, числовые файлы
`data/2026-10-18/` записаны, `data/latest.js` указывает на новую неделю, сайт
пересобран, весь прогон тестов зелёный. Это **первая неделя на таксономии
регионов v2** (12 регионов вместо 6): вход несёт атрибуции `regions[]` по 12 id,
сиды включают 12 × `region-*.js`, `week.js` собирается из 17 частей. Готовое
закоммичено; пуш в master (автовыкат) — отдельное действие, согласуется
с пользователем.

## Решения по реализации

- **Ярус — T2 (4 таска).** Исследование недели требует три независимых
  параллельных контекста (группы драйверов: D1/D5/D6 — D2/D3/D4 — D7/D8/D9),
  плюс интеграционный таск записи и публикации, заблокированный всеми тремя.
- **Неделя и цепочка.** Новая неделя добавляется в `RECALC_WEEKS` (`calc/calc.js`)
  ровно одной строкой — без этого CLI отказывается её считать. Прогон
  `--write 2026-10-18` идёт всей цепочкой от опубликованного `PREV_WEEK`
  2026-08-23 (инерция и региональные отклонения текут по цепочке), записывается
  только целевая неделя. Стартовое состояние и модель слепых регионов —
  существующие, без изменений.
- **Таксономия регионов v2.** `PARAMS.taxonomyV2From = '2026-10-18'`, поэтому
  `taxonomyForWeek('2026-10-18')` = `'2.0'`. Набор регионов недели —
  `regionIdsFor('2.0')` (12 id): east-asia, south-asia, middle-east,
  north-america, europe, africa (наследуют v1-офсеты из прошлых недель) +
  russia-belarus, ukraine-moldova, baltic, balkans, eu-north-europe,
  south-caucasus, central-asia (новые — без прежнего отклонения → слепые,
  background:true, index = I_global). Региональные атрибуции `regions[]` входа
  проверяются по whitelist 12 id; `week.js` собирается из 17 частей
  (`weekPartFiles('2.0')`).
- **Сбор данных.** Значения критериев выставляются по шкалам методологии
  (§4.2/§7.3: бинарные 0/1, порядковые 0/0.33/0.67/1, счётные — `value` или
  `events` из `severityValues`; D4.6 — ordinal 0/0.33/0.67/1), строго по фактам
  окна 12.10–18.10.2026, подтверждённым открытыми публикациями. Критерий без
  проверяемого сигнала — `null` (покрытие 27–43 из 46 — норма методологии).
  Пустых `covered:false`-объектов контракт не принимает — только `null`.
- **Источники.** Каждый покрытый критерий несёт ≥1 URL с датой публикации в
  окне (крайние даты 12.10 и 18.10), кластер из whitelist A–F; не более 2
  источников одного кластера на критерий (иначе `independenceWarnings` —
  независимость не подтверждена). Top-level `sources` — R55-схема
  (id/title{ru,en}/domain/url/publication_date/accessed_date/source_type/
  cluster_id/state_affiliated), те же URL, что и у критериев (иначе linkcheck
  проверит лишнее). Сайт блокирует 401/403/406 (Cloudflare/reuters-класс) —
  это `blocked`, ворота не роняет; 404/410 — битая, запись отклоняется, URL
  чинится или заменяется.
- **Сиды.** `data/2026-10-18/` создаётся с файлами `global.js` (min: `published`,
  `methodology` и `regions_taxonomy: "2.0"` — генератор берёт защищённые поля
  оттуда), `trend.js` (окно 12 точек = сдвиг окна 10-11: первая точка отпадает,
  добавляется `{"date":"2026-10-18","value":0}` — значение заменится расчётом,
  methodology проставится из сида global), `drivers.js` (3 драйвера, ru+en,
  2–5 источников каждый) и 12 × `region-*.js` (confidence + по 2 драйвера).
  `regions.js` и `sources.js` генератор пишет сам. Тексты драйверов — авторская
  редакционная сводка недели, созданная по результатам того же исследования.
  Для новых v2-регионов, слепых в этой неделе, сид несёт 2 региональных
  драйвера с источниками недели (иначе контракт региона отклонит) — тексты
  наднациональные по смыслу региона.
- **Публикация сайта.** `node build.js` обязателен: страницы грузят собранные
  бандлы. Правки `js/**` не предполагаются; `data/latest.js` — не JS-модуль,
  правится напрямую.
- **Тесты.** Прогон доказал, что три пина жёстко зашиты на 11 недель/v1 и
  обязаны обновиться под новую неделю (см. D01). `tests/data.test.js`
  (числовые пины 09-13) и `tests/sensitivity.test.js` (10-04 = 5.4) не меняются;
  пин `files.length >= 17` новым входом только подтверждается.

### D01 — поправка спеки по факту сборки (2026-10-18)

Первая неделя v2 добавляет 12-ю неделю в `CI_WEEKS` и меняет набор частей
`week.js` (11 → 17) для одной недели. Три теста были написаны на «все недели —
v1, 11 штук» и упали; это не регресс, а устаревшие пины, которые спека
ошибочно объявила неизменными:

- `tests/latest-loader.test.js` — ждёт 11 недель, `CI_LATEST`/`latest` =
  `2026-10-11`, 11 `document.write` → должно стать 12 / `2026-10-18` / 12.
- `tests/week-combined-parity.test.js` — перебирает `WEEK_PART_FILES` (заморожен
  на v1 = 11 частей) для всех недель и ждёт `WEEKS.length === 11` → должен брать
  `weekPartFiles(taxonomyForWeek(week))` и 12 недель.
- `tests/page-smoke.test.js` — требует `regions_taxonomy === '1.0'` и 6 строк
  витрины для всех недель → должен брать версию недели
  (`taxonomyForWeek(w)`/`snap.regions_taxonomy`) и `regionIdsFor(version).length`.

Правки тестов — часть таска 04 (зона расширена на эти три файла).
- **Аудит.** Записи recalc/flash в `data/audit.jsonl` добавляет сам пайплайн.

## Границы и швы

Новых модулей нет — работа идёт через существующие швы (спецификация на T0,
границы не создаются):

| Шов | Что проверяем |
|---|---|
| `engine.validate(input, PARAMS, regionIds)` | вход недели валиден (тесты и CLI) |
| `linkcheck.checkSources` | ворота запись/битая (CLI, `--write`) |
| `js/data.js validate` | контракт собранного снапшота (CLI, `--write`, тесты) |
| `taxonomyForWeek` / `weekPartFiles` / `renderWeekCombined` | версия набора и сборка week.js (тесты) |
| `node --test` | вся эталонная зелень |
