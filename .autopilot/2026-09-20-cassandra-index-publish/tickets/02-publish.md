## Что должно заработать

Существует публичный репозиторий `cassandra-index` в GitHub-аккаунте
пользователя, `master` запушен, GitHub Actions отработал, сайт отвечает по
публичному HTTPS-URL, и опубликованная версия проверена headless-браузером:
заголовок, индекс в hero, нет failed-запросов.

**ВАЖНО:** это действие наружу — выполняется только после подтверждения
пользователя. Без подтверждения таск не запускается.

- [ ] Actions-запуск завершился успехом, сайт отвечает по

      нет failed-запросов в консоли
