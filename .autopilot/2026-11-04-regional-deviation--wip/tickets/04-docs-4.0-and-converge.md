## Что должно заработать

Документы говорят о методологии 4.0 и не врут о фактах. `METHODOLOGY.md` §7
переписан под новую формулу (Δ по драйверам, `shrink_d`, знаменатель из весов,
`e_struct = 0.5` открыто как плейсхолдер, без `m`/`n₀`/`iWith`) — других
разделов файла править нельзя. ADR 0069 получает фактологические правки:
«13 недель» → «10» и скобка про дайджест приводится к фактической сортировке
`topRegions` (`|delta| → index → id`). `AGENTS.md`, `docs/architecture.md`,
`docs/calibration-journal.md` фиксируют переход на 4.0 с фактическими числами
после пересчёта. Ветка сходится: полный прогон зелёный, бандл собран,
порядок R12 выдержан (коммитит только оркестратор, субагенты не трогали git).
