# 10 — Сайт реально работает с file://

**Требования:** R63 (потребление данных; спека решила «сайт работает по двойному
клику, file:// блокирует fetch» — реализация это нарушила)
**Blocked by:** 11
**Зона:** `build.js` (корень, новый), `js/bundle.js` (генерируемый), `index.html`,
`privacy.html`; **без правки исходников `js/**`** (таск 11 их меняет — он раньше)
**Волна:** 10
**Status:** ready

## Почему таск существует

Слепая приёмка (G4, agent-28) доказала: сайт НЕ работает с file://. Chrome
блокирует ES-модули по CORS (`js/app.js`, `js/share.js` не грузятся) — живёт
только статичный RU-hero, секции пустые, язык мёртв. До приёмки никто не открывал
file:// в браузере (smoke-тест таска 06 не выполнялся). Требование из спеки
(Решение п.2): сайт обязан работать по двойному клику. Дрифт закрывается этим таском.

## Что сделать

Предпочтительное решение — сборщик без зависимостей:
- `build.js` (node ≥ 18, только stdlib) собирает ES-модули `js/` в `js/bundle.js`
  — classic script (импорты разрешаются в глобальный namespace, порядок — по графу
  зависимостей); `index.html` и `privacy.html` подключают bundle.js обычным
  `<script src defer>`;
- `js/bundle.js` коммитится (пользователь открывает сайт без сборки вручную);
  после правки исходников js/ сборка обновляется командой `node build.js`;
- `node --test` продолжает гоняться против исходных ES-модулей — зелёный;
- http-режим (`python -m http.server`) не ломается.

Альтернатива (отказ от ES-модулей в пользу глобальных скриптов) допустима только
с явным обоснованием в CONCERNS и если тесты продолжают работать без переписывания
всех файлов тестов.

## Доказательство — обязательно

Headless Chrome реально открывает `file:///…/index.html`: все 7 секций рендерятся
с данными, переключение языка работает, `?week=2026-08-30` показывает ту неделю,
console errors пустые. То же для `privacy.html`. Без headless-доказательства таск
не DONE. Команды запуска Chrome — в вернуть блоке.

## Критерии приёмки

- [ ] `file://` в Chrome: полный рендер, язык, ?week=, обе страницы, пустая консоль
- [ ] http-режим: как раньше
- [ ] `node --test` зелёный, против исходников
- [ ] `node build.js` воспроизводимо пересобирает bundle
