## Что должно заработать

Первый визит: человек открывает сайт и за 3 секунды видит всё, что нужно.
Sticky-хедер (blur 8px, --overlay-header, ≤64px / ≤88px моб.) с навигацией-якорями
и переключателем языка. Hero с дефолтной русской разметкой в исходном HTML:
заголовок-вопрос RU/EN дословно, строка-расшифровка, доминирующее число global 72/100,
один статус, одно Δ со знаком, обе даты («Последняя публикация» и «Данные по» —
визуально раздельны) и персональная строка региона с левой цветной полосой.
Регион определяется по часовому поясу браузера (первый визит ничего не сохраняет),
«изменить» открывает inline-панель: чипы «Регион · Город» с aria-pressed, поиск
с автокомплитом (~30 городов, стрелки/Enter/Escape, «Ничего не найдено»),
переключатель «Запомнить» (выкл по умолчанию → `cassandra.region`), кнопка
«Уточнить точнее» (HTML5 Geolocation только по клику, отказ — без изменений),
«Отмена» закрывает без изменений. После выбора города — обязательная приписка
«Это контекстный региональный риск, а не прогноз атаки на этот город.»
Нераспознанный пояс → нейтральный hero + CTA «Узнать риск для моего региона →».
Язык: дефолт по navigator.language, иначе ru; `cassandra.lang`; мгновенное
переключение без перезагрузки — все строки, aria, placeholder'ы, род, плюрализация, даты.

## Из брифа, дословно

> «В течение 3 секунд пользователь должен понять: … текущее состояние (global); состояние своего региона и название города; направление изменения; свежесть данных»
> «Первый экран — только то, что нужно для primary job, включая персональный региональный индекс и город. Продвинутые детали … — после взаимодействия»
> «Один доминирующий number (global), один вторичный number (region), один статус (global), одно направленное изменение, одно короткое уточнение. Без блока уверенности»

## Критерии приёмки

- [ ] Первый вьюпорт на 360×640 и на десктопе: заголовок, расшифровка, global 72/100, статус, ↑+6, персональная строка региона, обе даты — без скролла; в hero ровно 2 числа, 1 статус, 1 Δ
- [ ] Hero не содержит ничего из запретов §4.2.5 (обратный отсчёт, часы, шкала «безопасно→война», проценты ядерного риска, блок уверенности, пометка про IP, ≥3 крупных чисел); при индексе ≤80 красный #F85149 в hero не используется
- [ ] Часовой пояс маппится в регион+город; первый визит ничего не пишет в localStorage; нераспознанный пояс → нейтральный hero + CTA
- [ ] Панель выбора: чипы с aria-pressed, автокомплит (стрелки/Enter/Escape, текст не теряется, «Ничего не найдено» на языке интерфейса), «Запомнить» выкл по умолчанию, Geolocation только по клику и безболезненный отказ, «Отмена» без изменений
- [ ] После выбора города — приписка RU/EN дословно; без вероятностей удара, целей, времени
- [ ] Переключение языка мгновенное: html lang, title, meta description, aria-label/aria-live, placeholder, тултипы, названия регионов/городов, статусы обоих регистров, род («высокий вклад»/«высокая уверенность»), плюрализация, оба формата дат — без единой жёсткой строки
- [ ] Даты публикации и покрытия визуально раздельны; при недоступном регионе — «данные по региону временно недоступны», глобальный индекс показан
- [ ] Лексика: нет слов из Avoid §11.5 и фраз «на пороге/на грани»; заголовок без «война/начало/неизбежно/скоро/дата» (1 строка десктоп, ≤3 на 360px)
- [ ] Доступность и перф: видимый фокус, контраст, reflow 320px, touch ≥44px, значения не только цветом; core hero — в исходном HTML до выполнения JS
