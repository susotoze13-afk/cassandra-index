## Что должно заработать

Секция «Что изменилось / What changed»: три главных драйвера недели. Каждая карточка —
цепочка «Наблюдение → Почему это важно → Уверенность → Источники»: краткий лейбл,
одно предложение-наблюдение (по образцам PRD — наблюдения, не оценки; пометка
«независимо подтверждённых» где уместно), относительный вклад (высокий/средний/низкий,
RU с родом), уверенность (высокая/средняя/низкая) — при сниженной уверенности строка
причины: меньше данных / противоречащие независимые сигналы / неполное покрытие источников.
Кнопка цвета --accent «N источников» с правильным склонением (1/2–4/5+; EN 1 source/N sources),
chevron 90° при раскрытии, label меняется на «— скрыть», aria-expanded/aria-controls.
Раскрытие — ul/li/a: заголовок, домен, дата (дд.мм / MMM DD), target=_blank.
Демо-данные держат 2–5 источников на драйвер; 1 источник — всё равно кнопка «1 источник»;
>5 — первые 5 + «Показать все источники».
Вторая подсекция — дополнительные измерения без процентов: «Прямое военное столкновение —
Высокий/High», «Риск применения ядерного оружия — Низкий/Средний/Высокий»; раскрытие —
горизонт (12 месяцев), определение события, оговорка про калибровку.

## Из брифа, дословно

> «В течение 10–15 секунд пользователь должен понять три главные причины изменения и иметь возможность за один клик раскрыть источники»
> «Драйвер изменения обязан иметь раскрываемый список источников в один клик»
> «Для каждого драйвера: Observation → Why it matters → Confidence → Sources»

## Критерии приёмки

- [ ] Три карточки драйверов по цепочке Наблюдение → Почему это важно → Уверенность → Источники; формулировки — наблюдения, не оценки; спекуляции не подаются как факты
- [ ] Кнопка «N источников»: --accent, склонение RU 1/2–4/5+, chevron 90°, «— скрыть» при раскрытии, aria-expanded/aria-controls; клик раскрывает/скрывает; ссылка — заголовок+домен+дата в новой вкладке
- [ ] Уверенность — словами (высокая/средняя/низкая, EN High/Medium/Low) + причина при снижении; в карточках регионального списка (таск 05) — та же логика через общий компонент
- [ ] 1 источник → кнопка «1 источник»; >5 → первые 5 + «Показать все источники»; демо держит 2–5 на драйвер
- [ ] Доп. измерения: два уровня словами без процентов; раскрытие — горизонт 12 мес., определение события, оговорка про калибровку; в hero процентов нет
- [ ] Род согласован: «высокий вклад», «высокая уверенность»; всё переводится RU/EN без жёстких строк
- [ ] Клавиатура: аккордеон раскрывается с клавиатуры, фокус виден; значения не только цветом
