## Критерии приёмки

- [ ] `calc/calc.js`: `partOrder`/`renderWeekCombined` берут версию из
      `regions_taxonomy` global-части (а не по наличию v2-эксклюзивных `region-*`);
      при несоответствии набора и версии — явная ошибка, не молчаливый даунгрейд.
- [ ] `tests/calc-engine.test.js`: граница версий проверяется через вызов
      `taxonomyForWeek(week)`, а не повторением её выражения.
- [ ] `tests/insufficient.test.js`: пинит наблюдаемое «смещение нового региона не
      наследуется» (значения v2-id), а не остаточный ключ `prevRegions.europe`.
- [ ] `js/region.js`: поиск по id — один общий хелпер (убрать дубль формы
      `REGIONS_V2.find(x=>x.id===id)` в `get`/`choose`).
- [ ] `js/region.js`: результат поиска несёт `broad:boolean` и в fallback без
      каталога (`false`), контракт `.broad` выполняется в обеих ветках.
- [ ] `tests/region.test.js`: пин `search('Европа')` утверждает непустоту результата,
      а не вакуумное `every`.
- [ ] `js/geo.js`: убрать `geoSearch` как чистую обёртку без логики (единый вход
      поиска) ИЛИ явно закрепить его обязанность; поведение не дублируется.
- [ ] `data/geo/generate.js`: столицы добавляются только по суверенным странам
      (ISO 3166-1), не по `PPLC` любых территорий; `COUNTRY_RU`/маппинг регионов
      не расширяет список несуверенных.
- [ ] `tests/geo.test.js`: добавлены офлайн-тесты швов генератора на синтетике —

      `parseCountryInfo`, `buildRegionMaps`/`buildOutput`.
- [ ] `css/styles.css`: правило `.region-row--pinned` ограничено узкими вьюпортами
      (`@media`) и комментарий приведён в соответствие (обещание скролла убрано или
      реализовано `max-height`/`overflow` контейнера).
- [ ] `tests/page-smoke.test.js`: список недель берётся из канонического источника
      (`CI_WEEKS`/`listWeeks`), а не дублируется литералом.
- [ ] `node build.js` прогнан; `node --test` зелёный (число зафиксировать).
