## Что должно заработать

Появляется статический справочник городов и стран: города ≥50 000 жителей +
все столицы + 12 админцентров регионов, с русскими именами; страны с обеими
версиями региона. Справочник **не в бандле** и **не подключён статически** —
грузится лениво при первом открытии пикера, из кэша в памяти. Поиск от двух
символов по городам/странам/регионам, топ-20 по населению, fallback
город→страна→регион. Тесты работают без сети (по инъекции каталога).

## Из брифа, дословно

> «Скрипт-генератор фильтрует дамп `cities15000` по населению **≥50 000** … и добавляет поверх **все столицы суверенных стран (ISO 3166-1) + 12 административных центров регионов**»

> «они подгружаются динамическим `<script>` при первом открытии пикера …, с кэшем в памяти на время сессии»

> «**Минимум 2 символа**; при широком запросе — **топ-20 по населению** + подсказка «уточните запрос»»

> «Страна вне разбиения несёт `region_*: null`»

## Разделы спецификации

Решения §Справочник; Границы (`data/geo/generate.js`, `js/geo.js`, `js/region.js`).

## Критерии приёмки

- [ ] `data/geo/generate.js` (Node stdlib): скачивает `cities15000.zip` однократно,
      распаковывает встроенным zip-ридером (`zlib.inflateRawSync` + local file
      header), фильтрует по населению и добавляет столицы+админцентры; пишет
      `data/geo/cities.js` (`window.CI_GEO_CITIES`, `{name:{ru,en},country,region_v2,region_v1,pop}`)
      и `data/geo/countries.js` (`window.CI_GEO_COUNTRIES`, ISO2→`{name:{ru,en},region_v2,region_v1}`);
      сырой дамп не коммитится.
- [ ] Страна вне разбиения → `region_v2`/`region_v1` = `null`; `region_v1` страны —
      из таксономии 1.0, `region_v2` — из 2.0.
- [ ] `js/geo.js`: `loadGeo()` при первом вызове инжектит `<script>` (классические,
      работает с `file://`), резолвит `Promise<{cities,countries}>`, кэширует;
      повторный вызов — кэш. `resolveRegion(countryOrCity, catalog)`.
- [ ] `region.search(q, catalog)` — при `catalog` префиксный матч по ru/en городам +
      имена стран/регионов, минимум 2 символа, широкий → топ-20 + подсказка; без
      `catalog` — текущий `CITIES` (graceful fallback). Результат несёт `region_v2`.
- [ ] `build.js` не собирает `data/geo/*`; `index.html` их не подключает (тест).
- [ ] `data/regions/reference.json` — поле `cityImport` обновлено (задел закрыт).
- [ ] Тесты (без сети): форма данных, поиск (префикс/мин-2/топ-20), страна-как-fallback,
      `region_*:null`, ленивый загрузчик с подменённой инъекцией. `node --test` зелёный.

## Оговорка исполнителю

Дамп скачивается в сборке; если сеть недоступна — генератор готов, а данные
генерируются повторно при наличии сети. Вернуть `BLOCKED`, если дамп
недостижим и без него нельзя проверить форму.
