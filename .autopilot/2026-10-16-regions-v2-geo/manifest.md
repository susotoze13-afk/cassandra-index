## Самобрифинг (`full`, глубина обычная) — решения за пользователя

Режим полного автомата: вопросы не задаются. Решения, которые иначе были бы
вопросами, приняты за пользователя и помечены `ASSUMPTION`. Все они — строки
итогового отчёта (Фаза 8). Адверсариальный проход не запускался (глубина обычная).

| Решение (ASSUMPTION — принято за пользователя) | Строки |
|---|---|
| **Стек — существующий**: чистый HTML/CSS/JS, ноль зависимостей, Node stdlib; сеть только при однократной генерации справочника. Ничего не покупаем, аккаунтов не заводим. | R14, R15, R28 |
| **Дамп GeoNames `cities15000` скачивается один раз при генерации** через оболочку (`curl`/`fetch`); в репозиторий едет только сгенерированный `data/geo/*.js` + генератор, сырой дамп — нет. Если сеть недоступна — генератор готов, но данные/код-путь остаются; это риск сборки, не блокер. | R14, R15.1 |
| **Граница переключения таксономии = неделя пилота 2026-10-18.** Недели ≤ 2026-10-11 (демо 1.0 и цепочка 3.0) остаются v1 с их шестёркой; 10-18 и позже — v2. Переключение декларативно (по версии недели), не по факту перезаписи. | R05, R07, R08, R25 |
| **Пилот 2026-10-18 и его корпус — редакционные (человек).** Этот прогон готовит **код и пайплайн** под v2-неделю (calc.js пишет `regions_taxonomy` + 7 `region-*.js`, whitelist входа по версии), но сам R55-корпус по Балканам и публикацию недели 10-18 не выполняет — входа/сидов нет, `weekly-calc` тихо пропустит. Ворота качества корпуса держатся вручную. | R12, R13 |
| **Ссылка на лицензию GeoNames в `privacy.html`** добавляется (дёшево, честно). | R29i |
| **Термин `regions_taxonomy`** — имя поля снапшота; резолвер `regionIdsFor(taxonomy)`; отсутствие поля = `'1.0'`. Разрыв сеток раскрывается i18n-заметкой в секции истории. | R05, R07, R08.1 |
| **Совместимость важнее чистоты**: никакой ретро-правки данных 11 недель; глобальные числа и тренд не трогаются. Пин-тесты переписываются осознанно, но добавление v2 не должно ломать отображение v1-недель. | R08, R27, R30i |
