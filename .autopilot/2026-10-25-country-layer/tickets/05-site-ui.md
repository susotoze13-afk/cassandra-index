# 05 — Страновой блок на сайте

**Требования:** R08i
**Зависит от:** 02
**Зона:** `js/sections/regions.js` · `js/i18n.js` · `css/styles.css` · `tests/` · `js/bundle*.js` (сборка)
**Волна:** 4
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

В секции «Что это значит для моего региона?» под ranked-списком регионов —
под-блок «По странам»: строки опубликованных стран (имя из блока снапшота),
индекс и дельта; у слепой страны — пометка вместо дельты (как у регионов);
сортировка по |Δ|. На неделях без блока countries под-блок не рендерится и
страница не ломается. Все строки — из словаря `country.*`.

## Из брифа, дословно

> «по России и Ураине с ближайшей недели и далее шаг за шагом»

## Разделы спецификации

История 6; interfaces.md «Сайт».

## Критерии приёмки

- [ ] Чистый шов `countryRows(snapshot)` → `[{iso, name, index, delta, background, region}]`, null без блока; тесты шва
- [ ] Рендер только `createElement`/`textContent`; пометка слепой страны `country.background`; a11y-анонс через `[data-role="a11y-live"]`
- [ ] Ключи `country.title`/`country.background`/плюрализация `country.count` в `js/i18n.js`; недели без слоя — секция без изменений
- [ ] Стили по токенам (`--text-muted` для пометки), классы `.country-*`
- [ ] `node build.js` собран, бандлы обновлены; `node --test` зелёный (включая UI-тесты секции)
