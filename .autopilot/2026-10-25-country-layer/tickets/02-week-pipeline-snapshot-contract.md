## Что должно заработать

Недели, начиная с гейта, несут опциональную часть `countries.js`; набор частей по
версии таксономии не меняется (v1=11, v2=17), часть подхватывается по наличию
файла, рассинхрон даёт прежнюю явную ошибку. `writeWeek` для недель ≥ гейта с
валидным оверлеем пишет страновую часть и пересобирает `week.js`; с битым
оверлеем — строка «оверлей отклонён» и часть не пишется. `js/data.js` валидирует
опциональный блок `countries` снапшота.

## Критерии приёмки

- [ ] `weekPartFiles('1.0')` = 11, `weekPartFiles('2.0')` = 17 — прежние пины тестов не изменены
- [ ] `loadWeekParts` возвращает `countries` в parts, если файл есть на диске; `renderWeekCombined` принимает набор 17+countries для v2 и 17 без него; `countries` у v1-недели — явная ошибка
- [ ] `writeWeek` для недели ≥ гейта с валидным оверлеем вызывает запись страновой части и пересборку `week.js`; глобальные/региональные части при этом не перезаписываются адресно (только через прежний путь записи)
- [ ] `runWeek` печатает строку «страны: опубликовано M из N (...)»
- [ ] `js/data.js validateCountries`: отсутствие блока — валидно; ключи `/^[A-Z]{2}$/`; `index 0..100`, `delta` число, `background` boolean, `region` — id региона версии снапшота, `signals` int ≥ 0, `published ≤ total`; битые формы — ошибки в `validate`
- [ ] Все недели 08-02…10-18 валидируются прежне (блока нет — ок); `node --test` зелёный
