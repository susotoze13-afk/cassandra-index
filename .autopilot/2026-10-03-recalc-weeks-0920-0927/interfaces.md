# Границы и правила проекта

## Границы, решённые в спецификации

Изменений границ нет: пересчёт идёт через существующий CLI `calc/calc.js --write`
и существующие ворота (linkcheck + контракт `js/data.js`). Новых модулей нет (T0).

## Правила, которые субагент не может вывести сам

- Стек: чистый HTML/CSS/JS, ноль зависимостей, Node ≥ 18, всё ESM (кроме build.js).
  Ставить пакеты запрещено; отсутствующая возможность — вернуть BLOCKED.
- Тесты: `node --test` из корня, без аргументов (форма `node --test tests/` падает
  на Windows/Node 24). Один файл: `node --test tests/<имя>.test.js`.
- После ЛЮБОЙ правки `js/**` обязателен `node build.js`; бандлы коммитятся, руками
  не править.
- `node calc/calc.js --write <неделя>` требует сети (ворота ссылок): любой broken
  URL → запись отклонена; blocked (401/403/406/нет ответа) — только предупреждение.
  Обходить ворота запрещено.
- Фикстура `tests/data.test.js` пинит точные числа дисковых недель — после пересчёта
  актуализировать её под новые числа (конвенция, не баг).
- После записи недели — append в `data/audit.jsonl` (делает сам calc.js).
- Не трогать: `cassandra-index-prototype.html`, `PRD_Casandra_Index.md`,
  `METHODOLOGY.md`, `.autopilot/`.
- Коммит — НЕ делать: коммитит только оркестратор после приёмки.

## Швы для тестов

- `node calc/calc.js --write 2026-09-20` и `--write 2026-09-27` (в таком порядке) —
  полный путь через ворота.
- `node --test` — контракт и числа (tests/data.test.js).
