4. API-контракт и справочники
Публичный JSON уже отдаётся с Access-Control-Allow-Origin: *, ETag и cache. Не хватает контракта:
- data/public/schema/v1/*.json — JSON Schema;
- docs/api.md — эндпоинты, поля, версия, лицензия, примеры;
- data/public/regions.json — id, названия, таксономия;
- data/public/criteria.json — 46 критериев, драйверы, описания;
- data/public/methodology.json — веса, пороги, версия;
- data/public/weeks/<date>.json — понедельные файлы для кеширования и embed.
Это делает Cassandra источником, а не только сайтом. Дёшево, потому что данные уже есть.

Параметры запуска, переданные вместе с задачей: режим и параметры запуска — как
указано; если аргументы пусты — режим по умолчанию (`full`). Возможные режимы:
`full`, `semi`, `interview`, `manual`; модификаторы глубины: `strict`, `deep`,
`polish`; либо путь к файлу брифа.
