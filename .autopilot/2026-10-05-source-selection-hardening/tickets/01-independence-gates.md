# 01 — Ворота независимости источников на входе недели

**Требования:** R01
**Blocked by:** —
**Зона:** `calc/params.js` · `calc/calc.js` (`loadInput`) · `calc/engine.js` · `tests/`
**Волна:** 1
**Status:** ready

## Что должно заработать

В `loadInput` рядом с `validateInputSources` появляется новая проверка: каждый
покрытый критерий входа обязан иметь источники из ≥2 разных кластеров whitelist
`PARAMS.clusters` ИЛИ ≥1 источник с `source_type: primary|OSINT`. Ошибка входа →
неделя не считается (раньше linkcheck и контракта). Проверка применяется только к
неделям ≥ `PARAMS.independenceGateFrom` (breaking-константа `'2026-10-11'`,
комментарий по конвенции блока params) — опубликованная цепочка 08-30…10-04 не
трогается (A2). `state_affiliated: true` primary допустим (пометка — в таске 04).

## Критерии приёмки

- [ ] чистая функция проверки (шов для тестов) возвращает `string[]` по образцу `validateInputSources`
- [ ] неделя ≥ 2026-10-11 с покрытым критерием на 1 кластер/1 secondary → ошибка входа, расчёт не идёт
- [ ] тот же критерий с 2 кластерами → проходит; с 1 `primary|OSINT` → проходит (Provisional Primary)
- [ ] неделя < 2026-10-11 → проверка не применяется (фикстуры `tests/data.test.js` зелёные без правок)
- [ ] тесты ворот добавлены, `node --test` зелёный
- [ ] НЕ коммитить — коммит за оркестратором; правки только в «Зоне»
