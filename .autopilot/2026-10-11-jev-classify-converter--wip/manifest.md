# Манифест — jev-classify-converter

Авторитетная спецификация дизайна — в `docs/jev-classification.md` (v0.2, §3–§8)
и дополнении ADR 0018 от 2026-10-11. Этот прогон только реализует зафиксированное.

## Требования

| ID | Требование | Статус |
|---|---|---|
| R01 | `calc/classify.js` — чистый конвертер «черновик v2 → штатный вход»: чистые функции `normalizeText`, `quoteFound`, `validateDraft`, `reviewQueue`, `toInput`, `loadDraft` + тонкий CLI; вызов вручную, в CI не встроен | done (01) |
| R02 | Ворота правил 9–10 внутри конвертации: `quote` не найден в корпусе → запись отвергается (не «на ревью»), вход не эмитится; неразрешённый `review.flag`/`carryover` → вход не эмитится | done (01) |
| R03 | `tests/classify.test.js`: неразрешённая пометка → вход не эмитится; `quote` не найден → отказ; `events[]` не нормируется в `value`; `not_found` → `null`; merge нескольких записей одного критерия | done (01) |
| R04 | Конвенции репо: ESM, ноль зависимостей (только stdlib Node), стиль как `calc/engine.js`/`calc/linkcheck.js` (чистые функции, без сети), DOM не используется | done (01) |
| R05 | Полный `node --test` зелёный после реализации | done (01: 345/0, было 323) |

## Границы прогона (не требования)

- Форвард-прогон пилота, Jev, корпус текстов, доставка — вне этого прогона
  (данных черновика v2 ещё нет; конвертер строится и тестируется на синтетике).
- Документы дизайна уже написаны; править их не нужно, если код не открыл
  противоречия (тогда — `D##`-запись по правилам ремонта).
- `.autopilot/*`, `docs/articles/*` и прочее рабочее дерево параллельной сессии
  не трогать и не коммитить.
