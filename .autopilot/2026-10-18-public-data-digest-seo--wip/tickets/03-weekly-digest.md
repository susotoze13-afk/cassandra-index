## Что должно заработать

Раз в неделю после публикации снапшота собирается короткий выпуск «что изменилось»:
5 пунктов, 3 региона, ссылка на кривую. Он уходит в Telegram-канал и на адреса из
списка; у каждого выпуска есть публичный архив `digest.html`, а сам выпуск лежит
JSON-файлом. Пока секретов нет, доставка честно говорит, чего не хватает, — и ничего
не отправляет.

## Критерии приёмки

- [ ] `buildDigest` на снапшоте 2026-10-18 даёт: тему с датой недели, ровно 5 пунктов,
      ровно 3 региона, индекс/дельта/состояние, покрытие, ссылки на сайт, JSON, `trend.svg`
      и архив; `text`, `telegram` и `html` описывают одно и то же
- [ ] Снапшот без прошлой недели (`prev: null`) → `meta.hasPrev === false`, в тексте нет
      «изменение к …», падения нет
- [ ] `precursor` без поля в снапшоте не превращается в «0 %» — пункта о предвестниках нет
- [ ] `node calc/digest-send.js` без флагов — dry-run: печатает выпуск, ни одного запроса
      в сеть, `sent.json` не меняется
- [ ] `--send` без секретов → код выхода 1, сообщение называет имя переменной окружения,
      `sent.json` не меняется, значения секретов нигде не печатаются
- [ ] С поддельным `fetchImpl`: `sendTelegram` шлёт POST на
      `https://api.telegram.org/bot<token>/sendMessage` с `chat_id` и `text`;
      `sendEmail` шлёт POST на эндпоинт с токеном в заголовке; ответ 4xx/5xx → ошибка
      канала, `sent.json` не обновляется, код 1
- [ ] Повторный `--send` уже отправленной недели → `skipped`, без сетевых запросов,
      ненулевого кода нет
- [ ] `digest.html` генерируется: последний выпуск, до 12 ссылок на прошлые, ссылка на
      `data/public/digest/index.json`; при 13 выпусках — 12 и ссылка на полный список
- [ ] `data/public/digest/<week>.json` несёт `subject`/`text`/`meta`; `index.json` —
      список недель по убыванию
- [ ] `weekly-digest.yml`: cron по понедельникам + `workflow_dispatch [week]`, шаги
      «сгенерировать», «отправить», «записать `sent.json`»; секреты только именами;
      при отсутствии секретов шаг отправки завершается skip, а не красным
- [ ] `.env.example` содержит только имена (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`,
      `DIGEST_EMAIL_ENDPOINT`, `DIGEST_EMAIL_TOKEN`, `DIGEST_EMAIL_FROM`, `DIGEST_EMAIL_TO`)
- [ ] `node --test` зелёный; правок в `js/**` нет, `node build.js` не нужен
