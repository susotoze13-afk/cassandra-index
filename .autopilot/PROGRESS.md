## Известные баги

- Блог: опубликованные разборы 10-25/11-01 несут метку 3.0 и старые числа
  стран (RU 66/−2) при сайтах 67.1/+1.7 — нужна редакционная пересборка или
  пометка «историческое»; то же число «RU 66/Δ−2» осталось в `AGENTS.md`.
- `AGENTS.md`: утверждение «дельта слепого региона по построению равна
  глобальной» неверно с 4.0 (дробная точность: 08-30 east-asia −10.4 при
  глобальном −10).
- Личный регион переставляется первой строкой, а бейдж места показывает ранг
  по индексу (например 7) — порядок и номер рассинхронизированы осознанно,
  нумерация честная; уточнить визуально при желании.
- `renderWeekCombined` восстанавливает `signals` из части `regions` парсингом
  её JSON — смена формата частей тихо обнулит поле (запинено тестом).
- Латентно (флага нет ни в одной неделе): глобальная нога `delta`
  выбрасывает `intersection`; `stateOf(-1) = 'calm'` vs `status(-1) = null` на
  границах 0..100.
- Сторож grep `n0` в `tests/regional-deviation.test.js` ослаблен
  исключением `public-contract.js` (комментарий «удаляется своим прогоном» —
  прогон состоялся).
- `indices-audit.html` (производная) всё ещё называет
  `PARAMS.methodology = '3.0'` и «девять недель 3.0» текущими —
  пересборка `indices-audit-build.js --write` после смысловых правок.
- `stateOf` gapless полагается на восходящий порядок `PARAMS.states`
  (`calc/engine.js`) — неупорядоченный массив дал бы иное состояние.
- Спека говорит «article-build.js не трогается», а правка вынужденная
  (дробные числа для D01) — строка спеки устарела.
