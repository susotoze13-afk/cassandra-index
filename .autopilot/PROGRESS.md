# Cassandra Index — что осталось

Последняя сборка: `.autopilot/2026-10-19-api-contract-reference/` — контракт покрывает
весь публичный слой: 11 JSON Schema, `docs/api.md` по всем файлам, тест-сторож
«публичный JSON без схемы или строки в документе».

## Договорились — не пересматривать

- Контракт покрывает **весь** `data/public/**`, а не шесть названных путей: «иначе
  контракт отстаёт от диска и „источник“ получается неполным» (пользователь, 2026-10-19).
- `docs/api.md` живёт только в репозитории; страница `api.html` не заводится: «сайт —
  витрина, не справочник» (пользователь, 2026-10-19).
- Хвосты прошлой сборки в эту не берутся: «задача про API-контракт, хвосты к нему не
  относятся» (пользователь, 2026-10-19). Исключение — строка о генераторах
  `backtest.js`/`ledger.js` в `AGENTS.md`: контракт ссылается на их файлы.
- `PUBLIC_SCHEMA_VERSION = 1` не растёт: новых полей в существующих файлах нет,
  добавлены только описания ранее бесхозных файлов; добавление файлов — совместимо.
- Схемы держатся на ключевых словах, которые понимает минимальный валидатор
  `tests/public-contract.test.js`; nullable — массивом типов, не `anyOf`.
- Прошлые договорённости (лицензии по типу материала, ADR 0045 — UI не раскрывает
  формулы, порядковая шкала, forward-only `precursor`, `validation.json` из
  `backtest.js --write`, `forecast-ledger.json` из `ledger.js --write`) — в силе.

## Не доделано

- Новые пять схем (`changelog`, `digest`, `digest-index`, `validation`,
  `forecast-ledger`) ещё не на сайте: нужен push в `master` и выкат `deploy.yml`;
  до этого живые URL отдают 404.
- ACLED Conflict Index как композит не сравнивается (D01): композит полугодовой,
  машинного доступа нет (ADR 0063).
- Lead/lag по месячным рядам не считается: 2–3 точки, сдвиг неинформативен; механизм
  готов, ждёт истории.
- Фикстуры GPR/ACLED/CrisisWatch сняты на 2026-10-18 и сами не обновляются.
- Редакционных форвардных якорей нет ни одного; журнал показывает только baseline.

## Известные баги

- `docs/api.md`: в таблице `index.json` указано верхнеуровневое поле `methodology`,
  которого там нет — версия лежит в каждом элементе `weeks[]`.
- `docs/api.md`: сказано, что опубликованный выпуск дайджеста не переписывается, а
  `writeDigestData` пересобирает `<week>.json` каждой fresh-недели
  (`calc/digest-export.js`).
- `docs/api.md`: «до 12 записей» дублирует `MAX_DISCREPANCIES = 12` без пина тестом;
  примеры `validation.json` содержат `«…»` внутри объектов — копируются как невалидный JSON.
- Сторож `docs/api.md` ищет путь подстрокой: строки таблицы достаточно, подробный
  раздел можно удалить при зелёном тесте.
- `tests/public-contract.test.js`: nullable-тест покрывает не все nullable-пути
  (`direction.rate`, `overlap.from/to`).
- `calc/ledger.js`: `verified:null` не различает «нет коммита якоря», «нет коммита
  week.js» и «git недоступен»; `writeLedger` с `rootDir` без `anchorsDir` читает
  боевой `calc/input/anchors`.
- `calc/backtest.js`: ACLED за 2026-10 считается по 2026-10-09, но сравнивается как
  полный месяц; пометки нет.
- `calc/public-export.js --write` печатает «водопад: нет», хотя записанный
  `latest.json` содержит водопад (только строка отчёта, данные верны).
- `calc/public-export.js`: `trend.svg` рисует одну полилинию по всем 12 точкам,
  включая демо-недели методологии 1.0.
- `calc/quotes.js` не проверяет `id` источника на путь (`../`).
- `git clone` на Windows с `core.autocrlf=true` даёт падение двух тестов (CRLF).
