## Договорились — не пересматривать

- `intersection: true` в записи критерия = вторичный учёт события без нового аспекта:
  критерий покрыт, но не входит в скор драйвера, Д8, среднее подгрупп Д9 и региональные
  сигналы; граничный случай «все покрытые — пересечения» → 0 (не `null`), `null` = слепота.
- Флаг размечает уже принятое редактором решение; автоматической дедупликации по event ID
  нет и в этом прогоне не появилось (ADR 0046 отменяет §4 ADR 0045, §5 сохраняет).
- Пороги состояний (0–20 … 97–100, `js/risk.js`, METHODOLOGY §9) — публикационная шкала,
  не критерий отнесения к глобальному конфликту; §1.2 отвечает первой, код ссылается на неё.
- Цитаты — только дословные, только там, где есть корпус (ADR 0041/0042).
- `events[]` в якорях — только при точном воспроизведении значения (ADR 0043).
- Скалярная/ковариационная калибровка k×severity — вне рамок.
- Пуш в master — за пользователем.
