# Cassandra Index — что осталось

Последняя сборка: `.autopilot/2026-10-18-public-data-digest-seo/` — страница «Как читать
индекс», публичный слой данных (JSON/CSV/trend.svg + changelog), недельный дайджест с
архивом и доставкой, SEO-страницы сравнения с War Monitor/ACLED/CrisisWatch, sitemap,
robots и deploy-whitelist.

## Договорились — не пересматривать

- Публичный слой — **производная** от `data/<week>/week.js`: узкая проекция, детерминизм
  (никаких timestamp внутри), версия схемы в файле (ADR 0050/0051). Руками файлы
  `data/public/**`, `changelog.html`, `digest.html` не правятся.
- Шкала объявлена порядковой с прокалиброванными границами состояний; расстояния —
  соглашение насыщающей кривой, не измеренная величина (ADR 0048). Нормировка не менялась.
- Слой `precursor` в индекс не входит, public forward-only, бэкфилл запрещён (ADR 0047).
- Форвардные якоря: файл пишется до `--write`, параметры `k`/веса/пороги не трогаются до
  8 строк журнальной таблицы (ADR 0049).
- Статические SEO-страницы держат текст в разметке, без i18n-рантайма и без JSON-LD —
  осознанное исключение из правила «вся строка через словарь» (ADR 0052).
- Email-доставка — HTTP-эндпоинт провайдера, не SMTP-клиент (ADR 0053); провайдер
  выбирает пользователь.
- Отметка доставки — пары «неделя + канал» с резервом до отправки (ADR 0054); подписка
  на дайджест — заявкой через существующую форму, список адресов в секрете (ADR 0055).
- Число подгрупп Д9 — один источник `PRECURSOR_SUBGROUPS`, паритет пинится тестом.

## Не доделано

- Реальная доставка дайджеста не проверена end-to-end: нет Telegram-бота/канала и
  провайдера email — секреты пусты, `--send` не запускался (R18/R19 — заглушка).
- Лицензия публичных данных: `license.name/url = null` в `index.json` — нужен выбор
  пользователя (CC BY 4.0 или иное) и решение по атрибуции (R15i).
- `how-to-read.html` показывает пример недели 2026-10-18 (64 / +8) и не перегенерируется:
  через месяц страница датирована, но не «текущая».
- Черновик ответа комментатору — в чате, не в репозитории (прошлый прогон).
- Цитаты для десяти недель без корпуса — нужен сбор текстов (governance §10.1), не код.
- Полная ковариационная калибровка k×severity — вне рамок, отдельным прогоном.

## Известные баги

- `calc/public-export.js`: `trend.svg` рисует один полилинию по всем 12 точкам, включая
  демо-недели методологии 1.0 — сайт такие точки на тренде не показывает.
- `calc/public-export.js`: `changelog.json` берёт `schema_version` публичной схемы, хотя
  это другая схема; версия таксономии читается regex-ом из `global.js` с тихим фолбэком.
- `tests/seo-pages.test.js` пинит дату проверки фактов `2026-10-18` и утверждает, что
  контраст `--text-muted` ниже 4.5:1 — оба пина сломаются при законной правке.
- `tests/changelog.test.js` не проверяет, что дата записи не в будущем.
- `changelog.html` и `index.html` без `rel=canonical`/OG (у SEO-страниц и hub они есть).
- `calc/quotes.js` не проверяет `id` источника на путь (`../` уводит чтение корпуса).
- `calc/live-check.js`: `EXPECTED_WEEK_COUNT = 12` зашит литералом.
- `calc/calibrate.js` `loadAnchors` пропускает любой `*.json` без `input.anchor`;
  `validateForwardAnchor` принимает `committedAt` любой разбираемой датой.
- `git clone` на Windows с `core.autocrlf=true` даёт падение двух тестов (CRLF); при
  `core.autocrlf=false` — 660/660.
- `data/audit.jsonl`: повторные `--write` одной недели дают два recalc-среза.
- Параллельная сессия в том же дереве может перезаписать файлы: коммит `9d0f708` втянул
  половину таска 02, затем рабочее дерево потеряло эти ханки — восстановлено из HEAD.
