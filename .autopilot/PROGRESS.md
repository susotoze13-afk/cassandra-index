# Cassandra Index — что осталось

Последняя сборка: `.autopilot/2026-10-18-precursor-and-scale/` — интервальность шкалы в
журнале, публичный слой Precursor Risk (forward-only), форвардные якоря, ADR 0047–0049.

## Договорились — не пересматривать

- Шкала объявлена порядковой с прокалиброванными границами состояний; расстояния между
  числами — соглашение насыщающей кривой §5.2, а не измеренная величина (ADR 0048).
  Нормировку не меняли, числа недель не сдвинулись.
- Слой `precursor` не входит в индекс, публикуется отдельно, forward-only: на диске его
  нет ни у одной недели, бэкфилл запрещён (ADR 0047). Ноль и отсутствие поля — разные
  вещи: нет поля → блок скрыт, а не «0 %».
- Форвардный якорь — `calc/input/anchors/forward-<неделя>.json`, пишется до `--write`;
  `unknown` — законная запись с причиной; параметры `k`/веса/пороги не трогаются до
  8 строк журнальной таблицы (ADR 0049).
- Число подгрупп Д9 — один источник `PRECURSOR_SUBGROUPS` в `js/data.js`, паритет с
  движком пинится тестом.
- Слово «порядковая» публично (ADR 0045 и 0048) — прежняя договорённость «без этого
  слова» отменена на брифинге.

## Не доделано

- Черновик ответа комментатору — в чате, не в репозитории (R22i): его пишет оркестратор
  после приёмки.
- Первый форвардный якорь для 10-25 — пишет редактор до `--write`; сейчас файлов нет.
- Цитаты для десяти недель без корпуса — нужен сбор текстов (governance §10.1), не код.
- Полная ковариационная калибровка k×severity — вне рамок, отдельным прогоном.
- `calc/quotes.js` не проверяет `id` источника на путь (`../` уводит чтение корпуса).
- `calc/live-check.js`: `EXPECTED_WEEK_COUNT = 12` зашит литералом — 13-я неделя сломает
  проверку на исправном проде.

## Известные баги

- На проде блок предвестников скрыт до первой записи недели новым кодом — это ожидаемо
  по ADR 0047, но на живом сайте слой пока не увидеть.
- `calc/calibrate.js` `loadAnchors` пропускает любой `*.json` без `input.anchor`, не только
  форвардный: опечатка в модельном якоре молча убирает его из калибровки.
- `validateForwardAnchor` принимает `committedAt` любой разбираемой датой, не строго ISO.
- Слепая приёмка: текст про шкалу на сайте начинается «Шкала индекса порядковая», а в
  ранней части брифа было «без слова порядковая»; позднее дополнение «Ok» это разрешает.
- `git clone` на Windows с `core.autocrlf=true` даёт 513/515 (`tests/build.test.js`,
  `tests/week-combined-parity.test.js` ловят CRLF); при `core.autocrlf=false` — 575/575.
- `data/audit.jsonl`: повторные `--write` одной недели дают по два recalc-среза с
  одинаковым diff.
