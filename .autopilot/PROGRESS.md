# Cassandra Index — что осталось

Последняя сборка: `.autopilot/2026-10-18-license-and-citation/` — правовая рамка
репозитория: лицензии по типу материала (Apache-2.0 / CC BY 4.0 / CC BY 4.0), NOTICE,
торговая марка, `VERSION` + `CITATION.cff`, README с официальной фразой, вклад под DCO
с проверкой в CI, `SECURITY.md`, граница «публичное ядро / коммерческий модуль».

## Договорились — не пересматривать

- Лицензии разделены по типу материала: код — Apache-2.0, данные и документы — CC BY 4.0,
  название/логотип/домен — вне лицензий (`TRADEMARK.md`), чужие материалы — `NOTICE`
  (ADR 0058).
- Версия проекта — `VERSION` (semver), дублируется в `CITATION.cff`, паритет пинится
  тестом; версия методологии — не версия проекта (ADR 0060).
- Вклад — DCO 1.1 (`git commit -s`), CLA нет; проверка `tools/check-dco.js` сверяет
  подпись с автором (ADR 0059).
- Официальный источник один — cassindex.ru; форки неофициальны (фраза в `README.md`
  пинится тестом).
- Публичное ядро целиком здесь; коммерческий модуль — отдельный приватный репозиторий,
  закрытое зависит от открытого (ADR 0057).
- Публичный слой — производная от `data/<week>/week.js`, детерминизм, версия схемы
  (ADR 0050/0051). Руками `data/public/**`, `changelog.html`, `digest.html` не правятся.
- Шкала порядковая (ADR 0048); `precursor` в индекс не входит и forward-only (ADR 0047);
  параметры калибровки не трогаются до 8 строк журнала (ADR 0049).
- Статические SEO-страницы держат текст в разметке (ADR 0052); email — HTTP-эндпоинт
  (ADR 0053); отметка доставки — «неделя + канал» с резервом (ADR 0054).

  аккаунт Zenodo, привязка репозитория и первый релиз-тег (R09, отложено владельцу).
- Второй репозиторий под коммерческий модуль не создан: граница и процедура переноса

- Реальная доставка дайджеста не проверена end-to-end: секреты пусты, `--send` не
  запускался.
- `how-to-read.html` показывает пример недели 2026-10-18 (64 / +8) и не перегенерируется.
- Черновик ответа комментатору — в чате, не в репозитории.
- Цитаты для десяти недель без корпуса — нужен сбор текстов (governance §10.1).

## Известные баги

- `.github/workflows/dco.yml` исполняет `tools/check-dco.js` из самого PR: автор может
  ослабить свой гейт; надёжнее гонять копию из базовой ветки.
- В `how-to-read.html` версия `1.0.0` зашита в статику и сверяется тестом с `VERSION`:
  релиз правит два файла вручную.
- `CITATION.cff` объявляет одну лицензию `CC-BY-4.0` на весь репозиторий, хотя код под
  Apache-2.0.
- `SECURITY.md` обещает первый ответ за 72 часа — окно выбрано исполнителем, владельцу
  подтвердить или снять.
- `CONTRIBUTING.md`: опечатка в ссылке — раздел «Как цитировать» находится в `README.md`.
- `tests/licensing.test.js` требует `git` в PATH для проверки запрещённых каталогов
  (без него проверка пропускается).
- `calc/public-export.js`: `trend.svg` рисует одну полилинию по всем 12 точкам, включая
  демо-недели методологии 1.0.
- `calc/public-export.js`: `changelog.json` берёт `schema_version` публичной схемы.
- `tests/seo-pages.test.js` пинит дату проверки фактов и утверждение о контрасте.
- `calc/quotes.js` не проверяет `id` источника на путь (`../`).
- `calc/live-check.js`: `EXPECTED_WEEK_COUNT = 12` зашит литералом.
- `git clone` на Windows с `core.autocrlf=true` даёт падение двух тестов (CRLF).
