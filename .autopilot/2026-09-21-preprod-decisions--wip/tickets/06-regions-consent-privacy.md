## Что должно заработать

Версионированный справочник регионов (ISO 3166-2, админцентры, политика спорных
территорий, привязка к версии методологии); детерминированная лестница «что показывать
по уверенности» — чистая функция с тестами; согласие на определение региона: до
region_consent регион не определяется и не сохраняется, неблокирующий toast с кнопкой
«Изменить»; privacy.html описывает edge/браузерную модель, CCPA/GDPR/152-ФЗ,
отсутствие сырого IP.

## Детали

- `data/regions/reference.json`: версия методологии, 6 макрорегионов — ISO 3166-2
  коды стран, админцентр (city rep), политика: «город отображается в регионе по
  ISO 3166-2, нейтральная формулировка без политических утверждений», источник городских
  данных GeoNames (admin1_code → ISO 3166-2) — импорт городов при подключении edge-слоя.
  Сайт читает его через data/latest.js? НЕТ: latest.js грузит снапшоты недель. Справочник
  подключается отдельным script-тегом в index.html/privacy.html (window.CI_REGION_REF)
  либо инлайн-модулем region.js — решение исполнителя в рамках «сайт читает только
  data/»; файл должен лежать в data/ и попадать в деплой.
- Лестница (чистая функция `representative({cityConf, regionConf, city, adminCenter,
  regionId})`): cityConf≥0.8 → город; 0.5–0.8 → админцентр региона; regionConf≥0.9 → регион;
  <0.9 → только страна; регион не определён или любая ось <0.5 → глобальный. Границы
  включительно как в брифе; тесты ровно на 0.8/0.5/0.9/0.499.
- Согласие (region.js): `consent.status()` → 'granted'|'denied'|null + timestamp из
  localStorage (`cassandra.region.consent`). Без granted: detect() не вызывается,
  регион null (глобальный вид), sessionStorage-детект не пишется, toast показывается
  (не чаще раза за сессию). toast: кнопки «Изменить» (открывает пикер региона) и
  «Согласен»/закрыть; действие пишет granted+timestamp; «отказ» пишет denied (toast
  не повторяется до истечения 30 дней — хранить denied_until). Не привязывать к IP
  (IP у сайта нет и не будет — текст toast/privacy это подчёркивает).
- Hero: текущий tz-детект (js/region.js detect) вызывается только при granted; выбранный
  пользователем регион — как раньше. Панель пикера не меняется.
- privacy.html: новые разделы/правки — согласие region_consent (что хранится, как удалить),
  модель «edge/браузер»: сырой IP не попадает в инфраструктуру, на бэкенд только код
  региона (при появлении бэкенда), сейчас — только часовой пояс в браузере и только после
  согласия; CCPA (уведомление о сборе, право на отказ, раскрытие при передаче третьим
  лицам — сайт ничего не передаёт); GDPR законный интерес Art. 6(1)(f)/Recital 30;
  152-ФЗ: IP/cookie/гео — персональные данные с 2026, локализация в РФ, edge-геолокация
  вне РФ может быть нарушением — юридическая экспертиза обязательна (ссылка на
  docs/governance.md). Убрать/поправить устаревшие формулировки («первый визит ничего
  не сохраняет» → «до согласия ничего не сохраняется»; футер footer.ip на главной
  синхронизировать). Всё через data-i18n, строки в js/i18n.js (ru+en).
- Строки — только через словарь; DOM — createElement+textContent; toast a11y: role=status,
  aria-live polite (или кнопки с доступными именами), focus не воруется без действия.
