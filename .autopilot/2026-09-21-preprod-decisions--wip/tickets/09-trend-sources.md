## Что должно заработать

Тренд: на сенсорных экранах тап открывает bottom sheet (без автоскрытия, focus-trap,
возврат фокуса); desktop — tooltip по hover/focus без автоскрытия при фокусе; разрыв
серии при смене версии методологии между точками; полный a11y-контур (aria-label с
датой/индексом/состоянием, сводка aria-describedby, sr-only таблица, aria-live).
Источники: миграция всех демо-снапшотов на новую схему (id, title{ru,en}, domain, url,
publication_date, accessed_date, source_type, cluster_id, state_affiliated + опциональные),
сортировка тип→дата→домен везде, дефолт свёрнут с sessionStorage-expiry 30 минут,
иконка типа с tooltip.

## Детали

- Bottom sheet: определение touch — `matchMedia('(pointer: coarse)')` + fallback по
  первому touchstart. Sheet внизу экрана (position fixed), role=dialog, aria-modal=true,
  aria-label точки; содержимое: дата, индекс, состояние, Δ недели; закрытие: кнопка X,
  тап по подложке, Escape (a11y-дополнение к брифу); фокус внутрь при открытии,
  возврат на точку при закрытии; автоскрытия по таймеру нет (TAP_HIDE_MS удалить для
  touch-пути; hover-tooltip desktop остаётся с автоскрытием). Вибрация при листании
  точек на touch — navigator.vibrate(10) где доступно, без ошибок где нет.
- Точки: tabindex=0 role=button сохранить; aria-label «Дата: X, Индекс: Y, Состояние: Z»
  (через i18n, ICU-подстановка); svg role=img + aria-describedby на сводку
  («Сейчас: N из 100…» — существующая подпись, привязать id).
- sr-only таблица: 12 точек (дата, индекс, состояние) под графиком, caption из словаря.
- aria-live: при стрелочной/Tab-навигации по точкам announce текущей точки через
  [data-role="a11y-live"] (polite).
- Разрыв серии: точки тренда несут methodology (таск 05); при смене между соседними
  точками — разрыв линии (две subpath/два polyline) + подпись-маркер «смена методологии»
  со ссылкой на changelog (якорь methodology-секции); строка баннера breaking (R26)
  живёт в таске 10 — здесь только разрыв на графике и tooltip-маркер.
- Схема источников: js/data.js validate — обязательные поля id/title{ru,en}/domain/url/
  publication_date/accessed_date/source_type('primary'|'secondary'|'OSINT')/cluster_id/
  state_affiliated(bool); опциональные author/archive_url/archive_date/confidence/notes.
  Старые снапшоты (8 недель) мигрировать: id — стабильный из домена+пути; title —
  существующий {ru,en}; date → publication_date; accessed_date — дата публикации
  недели (through недели); type: по смыслу ('OSINT' для спутниковых/полевых, иначе
  'secondary' — выбор зафиксировать комментарием в файле); cluster_id — из маппинга
  существующих названий (таск 01) или 'A-mainstream' для мейнстрима; state_affiliated:
  false, кроме явно гос-СМИ (подписать комментарием). Миграция НЕ меняет отображаемые
  тексты.
- Сортировка: единая функция sortSources (тип: primary=0, OSINT=1, secondary=2; дата
  publication_date по убыванию; domain азбучно) — в истории и в аккордеонах драйверов/
  регионов; тесты порядка на фикстурах; иконка типа (строго через css-токены; aria-hidden
  + текстовая метка типа рядом) и tooltip «Сортировка: primary → дата → алфавит».
- Свёртка: аккордеон источников по умолчанию свёрнут (как сейчас); разворот —
  sessionStorage `cassandra.sources.open` с timestamp; чтение: разворот живёт ≤30 мин,
  истёк — свёрнут; новая сессия — свёрнут. Кнопка «N источников»/«скрыть» как сейчас.
