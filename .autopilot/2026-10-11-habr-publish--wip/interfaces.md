# Что уже построено

Читается исполнителем до начала работы. Не изобретай заново то, что здесь есть.

## Границы, решённые в спецификации

- `habr-post-final.md` — владеет телом публикуемой статьи. Выставляет markdown-текст,
  пригодный для вставки в редактор Хабра. Прячет структуру рабочих заметок источника
  и внутренние пути `docs/…`.
- `habr-publish-package.md` — владеет значениями полей редактора, картой вставки картинок,
  чек-листом модерации. Выставляет готовые к копированию значения. Прячет обоснования.
- Шов для проверки один: тело `habr-post-final.md`. По нему проверяется: нет заголовков
  ниже H3, нет вложенных цитат, нет ссылок на внутренние `docs/…`.

## Общие правила проекта (Cassandra Index)

- Ноль зависимостей, только stdlib. Никаких npm/CDN. Всё ESM, кроме CommonJS `build.js`.
- Тесты: `node --test` из корня (без аргументов). Один файл: `node --test tests/<имя>.test.js`.
  После любой правки `js/**` — `node build.js` (этот таск `js/**` не трогает).
- Вся пользовательская строка сайта — через `js/i18n.js`; этот таск сайт не трогает.
- Публикуемая версия статьи — только RU.
- Лексика: без слов из Avoid-списка PRD §11.5, без «на пороге/на грани» и метафоры часов.
- Не трогать: `cassandra-index-prototype.html`, `PRD_Casandra_Index.md`, `METHODOLOGY.md`,
  `.autopilot/` (кроме файлов этого прогона), чужие незакоммиченные правки в рабочем дереве.
- Чего не хватает — вернуть `BLOCKED` с описанием, не ставить пакет.
