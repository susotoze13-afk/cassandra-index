## Что должно заработать

Читатель раскрывает список источников драйвера (и региональной карточки) и под источником
видит дословную цитату с подписью «Цитата» и id критерия. В витрине доверия в раскрытии
появляется строка «С цитатой: N из M». У источника без цитат ничего не появляется;
десять недель без поля выглядят как раньше.

## Из брифа, дословно

> «Необходимо выкатить на пром хранение информации об источниках с циататми»

## Разделы спецификации

Истории 8–11; Решение §3; Решения по реализации (поиск по `url`, опциональность поля);
`interfaces.md` — `js/data.js`, `js/sections/drivers.js`, `js/sections/trust.js`, `js/i18n.js`.

## Критерии приёмки

- [ ] `isSource` принимает запись с корректным `quotes` и отклоняет битую форму
      (не массив, элемент без `text`, пустой `text`); запись без `quotes` валидна
- [ ] `quoteLookup(snapshot)` строится по `snapshot.sources` и ключу `url`;
      `quotesFor(source, lookup)` отдаёт `[]`, когда цитат нет
- [ ] `buildSourceItem` рисует цитату под источником (текст, подпись «Цитата», критерий),
      когда она есть, и не рисует блок, когда её нет
- [ ] региональные карточки показывают цитаты тем же путём (общий строитель), без второго рендера
- [ ] `trustFacts` отдаёт `quoted: {count, total}`, `factsLine` по-прежнему ровно 5 фактов,
      в раскрытии — строка «С цитатой: N из M»
- [ ] все строки — через `js/i18n.js`; DOM только `createElement` + `textContent`;
      цвета — токены `css/styles.css`; фокус/контраст не сломаны
- [ ] `node build.js` выполнен, `js/bundle.js` и `js/bundle-privacy.js` пересобраны
- [ ] `node --test` зелёный; `tests/page-smoke.test.js` проходит на всех 12 неделях
