# A1 — Список источников с цитатами в витрине доверия

**Требования:** A01 → R05i
**Зависит от:** —
**Зона:** `js/sections/trust.js` · `js/i18n.js` · `css/styles.css` · `js/bundle.js` · `js/bundle-privacy.js` · `tests/trust.test.js`
**Волна:** 5
**Ревью:** нет
**Модель:** обычная

## Что должно заработать

Читатель раскрывает витрину доверия недели и видит список источников с цитатами: название
источника, сам фрагмент и критерий. Это работает независимо от того, попал ли источник
в список драйвера или региона, — цитаты 09-27 сейчас видны только счётчиком.

## Из брифа, дословно

> «Необходимо выкатить на пром хранение информации об источниках с циататми»

## Разделы спецификации

Истории 8–11; Решение §3; `interfaces.md` — `js/sections/trust.js`.

## Критерии приёмки

- [ ] чистый шов `quotedSources(snapshot)` → массив `{title, url, quotes}` для источников
      с непустым `quotes`, порядок — по числу цитат (больше — выше), затем по домену
- [ ] `buildDetails` рисует блок «Источники с цитатами»: на источник — название (по языку),
      под ним каждая цитата с подписью «Цитата» и id критерия; блок не появляется, если
      цитат нет ни у одного источника
- [ ] `factsLine` по-прежнему ровно 5 фактов; строка «С цитатой: N из M» остаётся
- [ ] строки — только через `js/i18n.js` (RU), DOM — `createElement` + `textContent`,
      цвета — токены `css/styles.css`, контраст ≥ 4.5:1
- [ ] `node build.js` выполнен, бандлы пересобраны
- [ ] `node --test` зелёный; `tests/trust.test.js` покрывает пустой случай и случай с цитатами
