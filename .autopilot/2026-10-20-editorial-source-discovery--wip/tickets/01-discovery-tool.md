# 01 — Инструмент обнаружения источников и реестр лент

**Требования:** R01, R02, R09i
**Зависит от:** —
**Зона:** `calc/source-discovery.js` · `calc/input/discovery/` · `docs/source-discovery.md` · `tests/source-discovery.test.js`
**Волна:** 1
**Ревью:** да — фундамент
**Модель:** сильная

## Что должно заработать

Появляется CLI `node calc/source-discovery.js [--week <дата>] [--feeds] [--write]`: он берёт слепые
критерии недели (`criteria[id] === null` во входе `calc/input/<week>.json`), проверяет пул кандидатов
(файл `calc/input/discovery/<week>.json`, опционально — обход реестра лент `calc/input/discovery/feeds.json`)
и печатает по каждому кандидату вердикт OK/проблема с причиной: живой ли URL (через
`calc/linkcheck.js` с подстановкой fetchImpl — без реальной сети в тестах), дата публикации в окне
W−7…W, критерий из слепых, cluster_id из `PARAMS.clusters`, регион из whitelist таксономии недели,
заполнены обязательные R55-поля (id, title{ru,en}, domain, url, publication_date, accessed_date,
source_type, cluster_id, state_affiliated), форма `quotes[]` если есть. Сухой прогон по умолчанию;
`--write` кладёт машиночитаемое предложение в `data/discovery/<week>.json` (вердикт, блокеры, полный
R55-объект). Ни один код не пишет в `data/<week>/` и не вызывает `calc/calc.js`. Рядом —
задокументированная процедура `docs/source-discovery.md` (роли «модель предлагает / редактор выбирает»,
алгоритм недели, таблица реестра лент, курируется редактором); таблица документа — зеркало
`feeds.json`, их паритет пинится тестом.

## Критерии приёмки

- [ ] `node calc/source-discovery.js` (сухой прогон, без аргументов) печатает вердикты по кандидатам и не пишет файлов
- [ ] Кандидат с мёртвым URL (broken) отбраковывается с причиной; blocked — предупреждение, не отказ
- [ ] Кандидат вне окна W−7…W, с критерием не из слепых или cluster_id вне `PARAMS.clusters` — отбраковка с причиной
- [ ] `--write` создаёт `data/discovery/<week>.json` с вердиктами и полными R55-объектами; в `data/<week>/` ничего не меняется
- [ ] `calc/input/discovery/feeds.json` заполнен seed-реестром (регионы v2 + международные ленты), документ `docs/source-discovery.md` несёт ту же таблицу
- [ ] `tests/source-discovery.test.js` проходит: чистые функции на моке fetchImpl (без сети), форма JSON, паритет «документ ↔ feeds.json»; полный `node --test` зелёный
- [ ] Ноль новых зависимостей (только stdlib), логика в чистых экспортах, CLI — тонкая обвязка с `process.exitCode` (образец — `calc/check-sources.js`)
