# Cassandra Index

Официальный источник — cassindex.ru; форки не являются официальными.

Cassandra Index — публичный еженедельный индекс уровня и направления риска
глобального конфликта по открытым данным. Раз в неделю выходит число от 0 до 100,
состояние, изменение за неделю и три главных драйвера. Отдельно видно покрытие:
какие критерии подтверждены в окне недели, а какие остались без сигналов.

## Чего индекс не означает

- Не предсказывает дату войны и не отвечает на вопрос, случится ли конкретное
  событие.
- Не вероятность: число упорядочивает недели по уровню риска, а не измеряет шанс.
  Шкала порядковая, расстояние между значениями — соглашение модели, а не
  измеренная величина.
- Не официальная позиция правительства, международной организации или редакции.
  Это независимая оценка, и она может быть ошибочной.
- Не заменяет сообщения источников, полевую работу и решения организаций.
- Не прогноз для страны или города: региональное число — контекст, а не
  предупреждение об атаке.

## Быстрый старт

Зависимостей нет: сайт — статические HTML, CSS и JS, расчёт — модули Node.js.
Нужен только Node ≥ 18 для тестов и пересчёта.

```sh
# сайт: открыть index.html в браузере (работает и по file://)
# тесты: из корня репозитория, без аргументов
node --test
```

Один тест-файл: `node --test tests/<имя>.test.js`. После любой правки `js/**`
нужна пересборка бандлов: `node build.js` (бандлы коммитятся вместе с исходниками).

## Структура

| Путь | Что внутри |
|---|---|
| `js/` | сайт: оркестрация, контракт данных, рендер секций, таксономия регионов, словарь текстов |
| `calc/` | расчётный пайплайн: входные сигналы недели, движок методологии, калибровка, ворота публикации, публичный слой и дайджест |
| `data/` | снапшоты недель, публичный слой, справочник регионов и городов, журнал аудита |
| `tests/` | тесты `node --test` на чистых швах, без DOM и тест-фреймворков |
| `docs/` | архитектурные решения (ADR), описание потока данных, журналы калибровки и метрик |

Подробный поток данных и границы модулей — `docs/architecture.md`.

## Как цитировать

Каноническая формула — «Cassandra Index, версия, дата, URL»:

- **версия** — релиз проекта по semver (файл `VERSION`), а не версия методологии;
- **дата** — дата релиза или дата недели индекса, которую вы цитируете;
- **URL** — https://cassindex.ru.

Машинная форма лежит в `CITATION.cff`; GitHub и Zenodo читают её и предлагают
готовую ссылку. После первого релиза на Zenodo в `CITATION.cff` и в этом разделе
появится DOI. Если вы цитируете число недели, всегда указывайте дату недели:
индекс пересчитывается, и значение без даты теряет смысл.
