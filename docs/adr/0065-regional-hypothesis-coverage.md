# 0065. Региональные гипотетики §7: порог покрытия

**Дата:** 2026-10-24
**Статус:** реализовано (2026-10-24): `calc/engine.js` (`regionalHypothesisParams`,
четвёртый аргумент `regionalSignals`), `calc/params.js`
(`regionHypothesisThreshold`, `regionHypothesisFrom`), `calc/week-step.js`;
тест `tests/regional-hypothesis.test.js`

## Контекст

Региональная модель §7 считает отклонение региона через две гипотетики: `iWith`
— индекс «как если бы мир был только этим регионом» (по регионально
атрибутированным критериям) и `iWithout` — тот же прогон без сигналов региона.
Обе гипотетики идут тем же пайплайном §5 (`hypotheticalIndex` →
`buildDriversCore` → `driverScore`), поэтому молча наследуют глобальный порог
покрытия 50 % (`PARAMS.coverageThreshold`, §4.2).

В глобальном расчёте порог оправдан: драйвер сверяется с полным набором своих
критериев, и «покрыто меньше половины» означает «данных нет». В региональном
подмножестве набор по построению разрежённый — 1–7 атрибутированных критериев на
регион, — и тот же порог делает «часть данных» неотличимой от «нет данных».
Следствие на неделе 2026-10-18: у russia-belarus (7 сигналов) и ukraine-moldova
(5) все драйверы оказались ниже 50 %, `iWith = 0`, `Δ = iWith − iWithout`
упёрлась в клэмп −40, и регионы с активными боевыми действиями опубликованы на
8 и 7 п.п. **ниже** глобального фона — ниже регионов без войны. Механика и
числа разобраны в `docs/regional-iwith-degeneracy.md` (пункт O10
`docs/preproduction-decisions.md`).

## Решение

В двух вызовах `hypotheticalIndex` внутри `regionalSignals` порог покрытия
заменяется на эпсилон: драйвер гипотетики покрыт, если в региональном
подмножестве есть **хотя бы один** его покрытый критерий.

- Число — `PARAMS.regionHypothesisThreshold = 1e-9`, единственный источник.
  Не ноль: при `covered = 0` условие `0 < 1e-9` не выполняется, драйвер
  остаётся `null` — драйверов без региональных сигналов не появляется.
- Обе ноги Δ (`with` и `without`) считаются с одним порогом — сопоставимость
  сохраняется; `nReg`, `eStruct`, `eDyn`, `hasDeescSignals` не меняются.
- Гейт forward-only: `PARAMS.regionHypothesisFrom = '2026-10-25'`. Недели
  раньше даты считают гипотетики по глобальному порогу 50 %, то есть прежним
  поведением; опубликованная история не переписывается. Сравнение даты —
  строкой по ISO `YYYY-MM-DD`, как в `taxonomyForWeek` и
  `validateSourceIndependence`. Пустая или отсутствующая дата гейта — правило
  действует всегда; вызов без недели (чистый юнит) — тоже.
- Шов — `regionalHypothesisParams(params, week)` в `calc/engine.js`: чистая
  функция, возвращает исходный объект параметров или его копию с подменённым
  `coverageThreshold`; `params` не мутирует. `scoredCriteria` остаётся
  приватным, `driverScore`/`d8Strength`/`aggregateD9` не трогаются.
- `regionalSignals(criteria, regionIds, params, week)` — четвёртый аргумент
  опциональный; production-вызов один (`calc/week-step.js`), неделя берётся из
  `computeWeek`.

### Свойства варианта E (зафиксированы здесь как ожидаемые)

1. **Разрежённые регионы получают честную гипотетику.** На входе 2026-10-18 при
   гейте с этой недели `iWith`: russia-belarus 77.0 (было 0), ukraine-moldova
   60.0 (было 0).
2. **`central-asia` остаётся с `iWith = 0` — это легальный результат, а не
   вырождение.** Единственный атрибутированный сигнал — D3.4 деэскалационный:
   после α-клэмпа скор драйвера 0, гипотетика региона честно равна 0. Индекс
   региона остаётся 63 = опубликованному; правило «≥1 покрытого критерия»
   исполнено, фантомного драйвера нет.
3. **Одиночный сигнал `value = 1` даёт `iWith = 100` (africa, north-america), но
   сдвиг региона держится ≤ ~2 п.п.** — объёмное сжатие `m = nReg/(nReg+5)` и
   `e_r ∝ nReg` гасят одиночный сигнал. `nReg` у north-america = 1 при четырёх
   записях: Д2/Д4 исключены ADR 0022.
4. **`ukraine-moldova` в E ≈ 64 (чуть ниже глобального): `iWith` (60.0) <
   `iWithout` (66.2).** Сигналы недели включают деэскалацию (D3.4, D7.4, D8.3),
   поэтому гипотетика «только этот регион» ниже прогона без его сигналов. Это
   свойство данных недели, а не артефакт.

## Почему

- **Отвергнуто: вариант D — при `iWith == 0` считать регион слепым**
  (`docs/regional-iwith-degeneracy.md` §5). Слепая ветка сделана для регионов
  **без данных**, а не для разрежённых: в прототипе на 10-18 она схлопывает
  семь регионов в глобальный фон (новые v2-регионы без истории отклонения не
  имеют), убивая дифференциацию ровно там, где данные есть.
- **Отвергнуто: статус-кво.** Артефакт воспроизводится на каждой будущей
  неделе с размазанным покрытием и штрафует тем сильнее, чем больше у региона
  сигналов (пока `Δ` на клэмпе −40): russia-belarus −8, ukraine-moldova −7 п.п.
- **Отвергнуто: понижать глобальный `coverageThreshold`.** Глобальный порог —
  правило §4.2 с полным 46-критериальным контекстом; менять его значило бы
  сдвинуть индекс, `q`, состояния и чувствительность всех недель. Правка
  локальна для двух гипотетик.
- **Отвергнуто: ноль вместо эпсилона.** При `coverageThreshold: 0` пустое
  подмножество (`covered = 0`) тоже проходило бы порог, и гипотетика получала
  бы нулевой драйвер вместо `null` — фантомный драйвер вместо слепоты.

## Последствия

- Глобальный индекс, `delta`, `q`, состояние публикации и чувствительность не
  меняются: правило живёт только в `regionalSignals`, единственном потребителе
  `hypotheticalIndex`. Проверено печатью `node calc/calc.js 2026-10-18`:
  index 64, delta +8, регионы 56/58 — прежние (неделя раньше гейта).
- `data/**` и `data/public/**` в этой правке не пересчитывались: гейт
  `2026-10-25` отсекает всю опубликованную цепочку. **Охват истории —
  forward-only**; региональный пересчёт 08-30…10-18 (перезапись опубликованных
  значений, записи аудита, пересборка публичного слоя и дайджеста) — отдельное
  решение владельца, вынесено в O11 `docs/preproduction-decisions.md`.
  Без него неделя 2026-10-18 сохраняет прежние 56/58.
- Пин `tests/regional-signals.test.js` обновлён: `eu.iWithout` 0 → ≈ 37.65
  (D1 покрыт 1/6, по эпсилону S = 0.2). Пин `af.iWith === 0` сохранён: D5 нет в
  весах того теста, нормировка даёт 0 — это проверка весов, а не порога.
- `docs/regional-iwith-degeneracy.md` — исследование, не переписывается; его
  статус переведён в «решение принято».
- **Публичный контракт в этой правке не раскрыт:** `data/public/methodology.json`
  новых полей (`region_hypothesis_threshold`, дата гейта) не получает — это
  меняет публичную схему и `docs/api.md`, отдельный заход. Сейчас правило видно
  только в коде, ADR и тестах.
- `ADR 0022` не переписывается: 0065 его дополняет и переадресует — трактовки
  «сигналы региона → сравнение с остальным миром» не задавали порог гипотетики,
  теперь он задан явно.
