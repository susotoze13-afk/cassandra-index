# 0051: Версия публичной схемы в файле и детерминизм без отметок времени

**Контекст**
Публичные файлы читают чужие скрипты и таблицы, а собираются они заново при каждой записи недели. Нужен способ заметить смену состава полей и при этом не получать diff на пустом месте.

**Решение**
Каждый публичный файл несёт объявленную версию схемы; изменение состава полей — новая версия и запись в changelog. Содержимое детерминировано: порядок недель, регионов и драйверов фиксирован, дата генерации и любые отметки момента внутрь не пишутся — время выражают только даты недель и записи changelog.

**Почему**
Детерминизм даёт побайтовый паритет с диском и позволяет кэшировать файл по содержимому: пересборка без изменения данных не меняет файл. Отвергли отметку «сгенерировано»: она ломает паритет, даёт diff при каждом прогоне и сбрасывает кэш без причины. Отвергли версию в адресе каталога: два адреса на один ряд, редиректы и вечный вопрос, какая версия текущая. Отвергли версию только в changelog: читатель узнаёт о смене схемы после того, как сломался.

**Последствия**
Любая правка порядка или набора полей — ручное решение с подъёмом версии, а не побочный эффект рефакторинга; забытая запись в changelog делает версию бесполезной. Без отметки времени свежесть файла нельзя узнать из него самого — только по последней неделе в наборе.
