# 0013. Замена вымышленных URL источников на реальные статьи и миграция всех источников на схему R55

## Контекст

Все URL источников демо-снапшотов опубликованных недель — вымышленные пути на
реальных доменах (reuters.com, apnews.com, dw.com, un.org, sipri.org,
crisisgroup.org, bbc.com), отвечающие 404. Даты снапшотов — 2026 год, реальные
статьи этих доменов часто существенно старше недели снапшота. При этом полная
схема источника (id, title{ru,en}, domain, url, publication_date, accessed_date,
source_type, cluster_id, state_affiliated — решение R55 / ADR 0011) уже принята
контрактом `validate` (js/data.js) и рендером, а опубликованные записи сидят на
легаси-схеме `{title,url,domain,date}`.

## Решение

Каждый вымышленный URL заменяется URL реальной статьи того же домена (домен
сохраняется), максимально близкой по теме заявленного заголовка; при отсутствии
точного совпадения — ближайшая реальная статья домена по тематике раздела.
`title{ru,en}`, `date` и `domain` записи приводятся в соответствие реальной
странице — карточка не врёт. Все записи (`sources`, `drivers[].sources[]`,
региональные `sources[]`) мигрируют на полную схему R55 единым способом: id-слаг
строится от нового URL (отступление от первой редакции, легализованное ревью:
единая схема по всем источникам сайта лучше половинчатой).

## Почему

Вымышленный URL неисправим — ни ретрай, ни заголовок не сделают несуществующий
путь живым; только замена на реальный материал делает запись честной. Отвергнуто
оставить старые заголовки с новыми URL — карточка врёт читателю (история R02:
тема и дата соответствуют реальной странице). Отвергнуто менять домены — ломает
доверие к привязке источника: согласованность источника важнее близости даты,
домен — часть идентичности записи.

## Последствия

Часть записей имеет `publication_date` заметно раньше недели снапшота —
осознанный выбор: честность данных выше близости дат, читатель видит реальную
дату материала. Миграция на R55 затрагивает все опубликованные недели и должна
оставить `validate` и тесты зелёными. При обновлении недель оператор обязан
подбирать реальные статьи, а не сочинять URL — ворота linkcheck проверяют только
факт ответа страницы, не происхождение записи.
