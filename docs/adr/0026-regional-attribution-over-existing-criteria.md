# 0026. Региональная атрибуция — поверх существующих критериев и источников, плюс новые R55-записи

## Контекст

Механизм `engine.regionalSignals` (ADR 0022) умеет считать регион по сигналам,
но голоден: ни один вход недели не несёт `regions[]`, и все шесть регионов всех
недель слепы. Задача — наполнить существующий шов данными, не заводя второго
источника истины о регионах.

## Решение

Региональная атрибуция ставится **полем `regions[]` на уже существующих критериях
недели** (только драйверы Д1, Д3, Д5, Д6, Д7, Д8, Д9.3 — по ADR 0022), а источник
регионального сигнала остаётся **той же R55-записью** недели; новые региональные
источники добавляются в R55-списки лишь там, где существующего покрытия не
хватает. Отдельного реестра региональных источников не вводится. Правило
независимости (`≥2 кластеров ИЛИ ≥1 primary|OSINT`) применяется к каждому
покрытому региональному критерию **ко всем шести неделям** как редакционное
требование — зеркало ворот `validateSourceIndependence`.

## Почему

- **Отвергнут отдельный реестр региональных источников / параллельный контракт
  данных**: `regionalSignals` уже потребляет `criteria[].regions`, а `regions[]`
  уже валидируется против `REGION_IDS`; второй слой источников разошёлся бы с
  основным и размножил истину о регионах.
- **Отвергнута атрибуция без введения новых источников там, где покрытия нет**:
  регион, опирающийся на критерии, покрытые чужими (глобальными) источниками,
  не имел бы регионального подтверждения — сигнал был бы декоративным.
- **Отвергнуто ограничить правило независимости только окном кодового ворот**
  (`independenceGateFrom = '2026-10-11'`): недели 08-30…10-04 формально ниже
  даты ворот, но раз их всё равно пересчитывают под 3.0, оставлять их на базе
  одного кластера — значит публиковать динамику региона по одному рупору.

## Последствия

- Каждый покрытый региональный критерий требует ≥2 независимых источников;
  редактор обязан это выдерживать без кодовой поддержки на неделях до даты
  ворот — человеческий контроль, не автомат.
- Кандидат без публикации в окне недели W−7…W или без соответствия критерию
  отбрасывается **до** показа пользователю (дословная цитата-обоснование
  обязательна) — итоговый набор утверждает пользователь до `--write`.
- Атрибуция `regions[]` на Д2/Д4/Д9 (кроме D9.3) не запрещена схемой, но
  игнорируется агрегацией — `calc.js` печатает предупреждение, чтобы это не
  было молчаливым.
- Регион без единого сигнала честно остаётся слепым (`background:true`), пометка
  «региональных данных недостаточно» сохраняется; цель 4–6 регионов на поздних
  неделях — редакционная, не гарантия контракта.
