## Контекст

При билде `calc/engine.js` выяснилось несколько мест, где буква §4–§5 методологии либо непрактична, либо противоречива на реальных входах (покрытие 5/45 критериев). Отступления зафиксированы в коде и должны быть осознанными, а не случайными.

## Решение

Фиксируются четыре отступления ядра от методологии: (1) порог покрытия 50 % не применяется к подгруппам Д9 — подгруппа даёт null только при нуле покрытых критериев; (2) единственная изолированная циклическая подгруппа Д9 получает corr 0.5; (3) лимит 30 % Д9 реализован закрытой формой относительно прогона без Д9; (4) персистентность Structural Break Override (2 недели) — состояние цикла несёт `calc.js` через ctx, а не engine.

## Почему

Отвергнута прямая реализация порога 50 % для подгрупп Д9 — при реальном покрытии почти каждая подгруппа уходила бы в null, и драйвер Д9 систематически выпадал бы из индекса, что хуже, чем ослабленная короборация по частичным данным. Отвергнуто оставить изолированную циклическую подгруппу без коррекции — изолированность одной подгруппы делает её короборацию неопределённой, и без фиксированного corr 0.5 результат был бы нестабилен/невоспроизводим. Отвергнут итеративный (численный) расчёт лимита 30 % Д9 — закрытая форма детерминирована, тестируема и не требует сходимости; итерация добавила бы скрытую логику в чистые функции. Отвергнуто хранение состояния SBO внутри engine — нарушило бы чистоту функций, единственный тестовый шов репозитория; состояние цикла перенесено на CLI-обвязку.

## Последствия

Engine расходится с буквой методологии в четырёх точках: при пересмотре METHODOLOGY.md отступления надо либо устранить в коде, либо легализовать в тексте методологии — молча рассинхронизироваться нельзя. corr 0.5 и закрытая форма — экспертные допущения, не выведенные из данных; они должны быть перепроверены при полном бэктесте (открытый вопрос №1). Состояние SBO в ctx calc.js — неявный контракт: любой другой вызывающий engine (например, расчёт регионов) обязан воспроизвести несение состояния, иначе персистентность сломается молча.
