# 0016. Предпродакшен-документ: сверху только нерешённое, решённое — в архивный раздел, а не удаление

## Контекст

Документ «Открытые вопросы перед продакшеном» утоплен в уже решённом: B1–B6, P1
и §2–§5 закрыты, но занимают основной текст, и читатель не может отличить
живые вопросы от истории. Бриф требует оставить в списке только нерешённые.

## Решение

Документ перестраивается в два слоя: сверху — только открытые вопросы
(фактически пять пунктов P2 «после запуска»), решённое переносится в конец в
архивный раздел «Решено» с сохранением формулировок и контекста; версия
документа поднимается. Ничего не удаляется бесследно. Зафиксировано в манифесте
прогона как допущение A-R04.

## Почему

Отвергнуто удаление решённых пунктов: бриф снимает их из поля зрения, но не
отменяет — без истории решений повторное обсуждение того же вопроса начнётся с
нуля, а ссылка «почему так решили» исчезнет вместе с пунктом. Отвергнуто
разделение на два файла («открытые» / «архив»): один документ с явным архивом
проще синхронизировать (один источник правды о статусе вопроса) и дешевле для
читателя, чем навигация между файлами.

## Последствия

Документ будет расти вниз за счёт архива — нужна дисциплина версий и дат в
разделе «Решено», иначе через несколько прогонов архив станет шумом, который
бриф и хотел убрать. Статус «открыт/решен» живёт только в этом файле: снятие
пункта = редакторское действие вручную, автоматической сверки нет. Строку A-R04
из манифеста может снять только пользователь.
