# 0012. Трёхзначная классификация исхода проверки ссылки (ok | blocked | broken)

## Контекст

Бриф требует проверять работоспособность ссылок-источников на пути публикации,
но сборка воркера показала (наблюдения D01–D03), что из среды проверки живые
страницы отдают не-успешные ответы: 403 на любые bot-запросы (Cloudflare JS-challenge
на apnews.com, crisisgroup.org, iaea.org), интермитентный 406 (бот-фильтр
reliefweb.int — те же URL через минуту отдают 202), а DNS среды не резолвит
www.bbc.com и www.dw.com (страницы живы — 200 через --resolve). Бинарное «2xx —
жива, иначе битая» неотличимо ложит на живые источники и живые сети.

## Решение

Исход проверки URL классифицируется тремя значениями: `ok` (2xx/3xx), `blocked`
(403, 406, `null` — ответ не получен из-за DNS/таймаута/обрыва), `broken` (404/410
и прочие 4xx/5xx после исчерпания ретраев). Ворота пайплайна падают только по
`broken`; `blocked` печатается предупреждением и публикацию не останавливает.
Запросы идут с браузерными заголовками (User-Agent, Accept: text/html); на 429/5xx/406
и таймауте — повтор с задержкой в пределах лимита попыток. Классификация и проверка
— чистые функции (`classify`, `checkUrl`, `checkSources` в `calc/linkcheck.js`),
тестируемые с поддельным fetch без сети.

## Почему

«Проверять работоспособность» ≠ «падать на ложных срабатываниях»: недоступность
страницы из среды проверки (bot-фильтр, DNS-резолвинг среды) не доказывает, что
страницы нет — а ворота, ложно блокирующие живые источники, делают публикацию
невозможной и саботируют само требование проверки. Отвергнуто «любой не-2xx =
битая» — ложно блокирует живые страницы (D01–D03). Отвергнуто «любой не-2xx =
ок» — пропускает реально мёртвые 404/410 и сводит проверку к декорации.

## Последствия

Битый домен, отвечающий 5xx, всё же ворота пайплайна (broken), а «ответ не
получен» — нет: оператор должен понимать, что null из среды не блокирует запись.
Blocked-список не останавливает публикацию и требует глаз оператора при публикации
— он валидирует предупреждения по смыслу, а не по коду выхода. Классификация —
константы поведения модуля, не параметры запуска.
