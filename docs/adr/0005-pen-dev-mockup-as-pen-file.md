# 0005. Дизайн-макет — файл `design/cassandra-index.pen`, написанный напрямую в формате pen.dev

## Контекст

Брифинг G01: «разработай дизайн макет в pencil dev» — принят как pen.dev (Pencil, Evil Martians; расширение VS Code `highagency.pencildev`). Плановый путь — работать через приложение pen.dev/MCP. При сборке выяснилось: приложение в сессии не запущено, MCP-сервер требует живое приложение, поэтому прямой путь через инструмент недоступен.

## Решение

Макет создаётся как текстовый файл `design/cassandra-index.pen` (JSON-формат .pen, version 2.6) в репозитории, написанный вручную по документации формата из расширения. Деливерабл — документ-канвас с экранными фреймами (Desktop 1440: hero, секции, ranked-лист+футер; Mobile 360×640), палитра строго из токенов PRD §14.4. Корректность файла гарантирует `tests/pen.test.js` (node --test): парсинг JSON, наличие обязательных фреймов, палитра, инварианты формата (нет процентов, у text-нод есть fill, фреймы top-level с clip).

## Почему

Рассмотрены: (1) поднять приложение pen.dev ради макета — отвергнуто: требует интерактивной сессии, недоступной в автономной сборке, и не даёт преимущества для разового деливерабла; (2) макет как набор скриншотов/PNG — отвергнуто: не редактируем, не сверяется с токенами, несовместим с требованием «разработай макет в pencil dev»; (3) отложить G01 до появления живого приложения — отвергнуто: макет блокирует приёмку IA и визуальных нормативов. Написание .pen напрямую — легитимный способ создания документа; файл открывается в pen.dev как обычный, то есть макет остаётся редактируемым артефактом, а не одноразовым экспортом.

## Последствия

Файл — источник истины для макета, но его нельзя править вслепую: формат подробен и капризен (flexbox-раскладка, `textGrowth`, запрет процентов/margin). Пересохранение файла в приложении pen.dev перезаписывает поле `"version"` → ломает `tests/pen.test.js`, жёстко ожидающий текущую версию; после правки в приложении версию в тесте надо обновлять вручную. Тест проверяет структуру и токены, но не визуальное качество — design-review глазами остаётся отдельным шагом.
