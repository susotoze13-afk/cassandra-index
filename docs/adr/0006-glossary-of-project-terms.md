# 0006. Словарь терминов проекта (нормативные определения из спецификации)

## Контекст

Проект использует ряд терминов в собственном смысле, зафиксированном в спецификации сборки v1.3; PRD дополнительно нормирует лексику через список Avoid §11.5. Расхождение толкований между кодом, тестами, методологией и будущими редакторами данных дорого обходится: меняется схема данных, словари i18n и юридически значимые тексты.

## Решение

Нормативные определения: **индекс** — целое 0–100, состояние риска, не вероятность войны и не обратный отсчёт; **драйвер** — одна из ровно 3 причин изменения индекса за неделю, по цепочке «Наблюдение → Почему это важно → Уверенность → Источники»; **снапшот** — неизменяемый недельный набор данных с датами `published`/`through` и версией методологии; **статус риска** — словесная ступень шкалы §10 (Спокойно…Экстремальная угроза), вычисляется из индекса, а не хранится в данных; **модельный риск** — допустимая формулировка крит-режима (индекс ≥81), никогда не «объявлена ЧС» и не «война началась»; **уверенность** — отдельная оценка (высокая/средняя/низкая) у драйвера и в региональной таблице, в hero отсутствует; **город-представитель** — ярлык региона для пользователя, значение индекса всегда региональное; **крит-режим** — состояние UI при global.index ≥81, функция данных, не кнопка; **источники** — 1–5+ раскрываемых ссылок на драйвер, плюрализация 1/2–4/5+.

## Почему

Словарь зафиксирован, потому что у ключевых терминов есть соблазнительные «бытовые» прочтения, которые нарушают PRD: «индекс» как «вероятность в %», «уверенность» как «насколько модель уверена, что война будет», «город» как «оценка риска удара по городу» — все три прямо запрещены (R03, R27, R14/R50). Термин «статус» отделён от «индекса», чтобы не плодить два источника правды (см. ADR 0004). Термины из списка Avoid §11.5 (триггер, baseline, дельта, выход модели и т.д.) технические и допустимы только в методологии — в primary UI они создают ложную точность.

## Последствия

Любой новый текст (новая неделя, новый драйвер, правка методологии) обязан использовать словарь как есть; «вероятность», «прогноз», «до войны» — не слова этого проекта. Смена термина — это правка словарей RU/EN, тестов и, возможно, схемы снапшота, то есть версионируемое изменение, а не косметика. Открытый вопрос PRD §19 «статистическая интерпретация индекса» остаётся открытым: словарь фиксирует, чем индекс НЕ является, но не даёт интерпретации, чем он является в статистическом смысле.
