# Дозабор источников недели 2026-10-18: 19 слепых критериев

**Дата работы:** 2026-10-18
**Окно недели:** 2026-10-11 … 2026-10-18 (W−7…W включительно)
**Задача:** найти подтверждающие сигналы для 19 критериев, у которых в
`calc/input/2026-10-18.json` стоит `null`:
D1.2, D1.6, D2.4, D3.1, D5.2, D5.3, D5.4, D6.1, D6.2, D6.4, D7.4, D8.4,
D9.1, D9.2, D9.4, D9.5, D9.6a, D9.6b, D9.7.

**Итог:** покрываемым в окне оказался **один критерий — D1.2** (учения необычного
масштаба), найдено 5 источников в трёх независимых кластерах. Остальные 18 —
`searched-none`: сигналов в окне нет ни в доступных новостных потоках, ни в
редакционных подборках. Проверка шла в два прохода (Bing News HTML + RSS-выдача
+Bing News за 7 дней, Wikipedia Current Events, RSS изданий); второй проход
добавил только отбракованные кандидаты, ни одного нового покрытия не дал.
Ниже — доказательная база, реестр отбраковки и готовый патч. Вход недели
**не изменён** (см. «Почему патч не применён»).

## Метод и ограничения среды

- Поиск: Bing News API-выдача (`interval=7`, т.е. окно недели), Wikipedia
  Current Events (11–18 октября, raw), RSS доступных изданий (Al Jazeera,
  The Guardian, TASS, The Jerusalem Post), прямая проверка страниц `fetch`.
- WebSearch/WebFetch-поиск и DuckDuckGo в этой среде упираются в 403/captcha,
  GDELT DOC API отдаёт 429 после нескольких запросов — рабочий канал Bing News
  + прямая выборка. Все найденные URL проверены на доступность и дату.
- Блокированные сети редакции (403/401/000) в реестр идут как `unavailable`,
  а не как битые: `linkcheck.classify` трактует их одинаково — `blocked`.

драйвер Д1.
