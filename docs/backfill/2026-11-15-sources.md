# Реестр дозбора источников, 2026-11-15: 20 слепых → 0

**Дата недели:** 2026-11-15
**Окно сбора:** 2026-11-09 → 2026-11-15 (W−6…W, ADR 0073)
**Статус:** слепые критерии 20 → 0; покрытие 26/46 → **46/46**; источников 85 → **139**.

Работа шла в три прохода. Первый закрыл восемь критериев (26/46 → 34/46),
второй — ещё восемь (34/46 → 42/46), третий — последние четыре (42/46 → 46/46).
Из последних четырёх один закрыт положительным сигналом (D5.4), три — измеренным
нулём: в окне не было события, но критерий закрыт наблюдением и раскрыт
в `driverConfidence`, а не оставлен слепым.

Первая версия входа собрала 26 критериев из 46 (Reuters, AP, ISW, DW, часть
ведомственных сайтов из среды сбора недоступны). Этот прогон расширил именно пул
источников, а не трактовки: по восьми слепым критериям найдена вторая независимая
сторона (или первичка), и только после этого критерии получили значения. Ни один
критерий не покрыт источником, которого нет в `calc/input/2026-11-15.json`;
значения — из события недели, а не из повестки.

**Почему это не «слепые точки, посчитанные за ноль».** Для D2.4, D6.4 и D8.4
целевой поиск дал не пустой результат, а наблюдение: что именно происходило
в домене критерия и почему положительного сигнала нет. Ноль записан как
измеренное значение (`covered: true, value: 0`) с двумя кластерами источников
и раскрытием в `driverConfidence`; `blindReasons` очищен. Это отличается
от прежней практики «не нашли — оставили слепым» и зафиксировано здесь явно.

Слепых критериев в неделе не осталось: `blindReasons` — пустой объект,
`coverageCriteria.uncovered` — пустой массив, долг истории — 0.
