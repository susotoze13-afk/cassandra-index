# Реестр дозбора источников, 2026-11-15: 20 слепых → 12

**Дата недели:** 2026-11-15
**Окно сбора:** 2026-11-09 → 2026-11-15 (W−6…W, ADR 0073)
**Статус:** слепые критерии 20 → 12; покрытие 26/46 → **34/46**; источников 85 → **115**.

Первая версия входа собрала 26 критериев из 46 (Reuters, AP, ISW, DW, часть
ведомственных сайтов из среды сбора недоступны). Этот прогон расширил именно пул
источников, а не трактовки: по восьми слепым критериям найдена вторая независимая
сторона (или первичка), и только после этого критерии получили значения. Ни один
критерий не покрыт источником, которого нет в `calc/input/2026-11-15.json`;
значения — из события недели, а не из повестки.

## Что осталось слепым и почему

Причины — из `blindReasons` входа (ADR 0040): **gate-failed** — событие в окне
было, но подтверждение одним кластером источников (ворота независимости не
пройдены), таких пять; **searched-none** — искали, в лентах окна сигналов не
нашлось, таких семь.

## Пересчёт и эффект на число

`node calc/calc.js --write 2026-11-15` (ворота ссылок пройдены: broken 0):

- было: index **74**, Δ **+5**, внутренний 73.784, покрытие 26/46;
- стало: index **70**, Δ **+1**, внутренний 69.898, покрытие **34/46**, q = 1.

Число снизилось не из-за новых событий, а из-за самого покрытия:

- Д1 собрал 6 критериев из 6: скор драйвера 0.51 → 0.41, потому что боевая
  сводка (D1.4 = 1.0) перестала быть единственной ногой, а вывод войск (D1.6)
  работает вниз (α · 0.33);
- Д8 впервые увидел работающее перемирие (D8.1 = 1.0): сила деэскалации
  0.33 → 0.55, а она вычитается из индекса;
- Д7 получил новый фронт (D7.3 = 1.0) — единственный заметный рост.

Водопад недели: −2,6 (Д1), +5,1 (Д2), −5,2 (Д3), +3,2 (Д4), 0,0 (Д5),
+1,0 (Д6), +4,7 (Д7), −3,0 (Д8), +1,2 (Д9), остаток −3,4 → **+1**.

**Flash.** Новый фронт (D7.3) сработал как flash-триггер: запись в
`data/audit.jsonl` (alert only, снапшот не меняется) — вместе с D1.4.
