# Конкурентный анализ: WarMonit.com (War Monitor)

*Дата: 24.10.2026 · Составлено для: Cassandra Index · Источники: собственно сайт warmonit.com (about, methodology, pro, press, terms, llms.txt, sitemap, открытые data/endpoints), RDAP Verisign, Internet Archive CDX, lite-DuckDuckGo, HN Algolia, cutstaff.io, tech.warmonit.com*

---

## Executive Summary

WarMonit — это **одиночный продукт одного болгарского разработчика** (Rumen Slavov, PRO WEBSITE EOOD, Варна), запущенный **в начале марта 2026 года** (домен зарегистрирован 02.03.2026, первая Wayback-запись 03.03.2026). Позиционирование: «бесплатная, многоязычная мониторинговая система по войнам: живая карта конфликтов, ежедневная сводка в 06:00 UTC и глобальный уровень угрозы 0–10 с публичной историей». Продукт моложе Cassandra Index примерно втрое, но двигается агрессивно: монетизация уже запущена (Pro от €9/мес через Creem), 12–16 языков, API-план, Android-приложение, SEO-ферма «answer-страниц» (WW3, DEFCON, сколько сейчас войн, безопасно ли летать в Х) и вертикальный сосед tech.warmonit.com. Методология простая и полностью описательная (индекса предсказаний нет — есть Pro-«forecasting AI» с вероятностями), данные — ACLED/UCDP/GDELT + OSINT/рынки. Внешних отзывов, освещения и следов клиентской базы **практически нет** — продукт пока существует почти целиком в своей SEO-экосистеме.

## 2. Ценность (value proposition)

Для обычного пользователя: «одна карта + одно письмо в день = знать, где сейчас воюют и насколько опасен мир, без полит-шума». Плюс приличный дисклеймер: «не является прогнозом и не записью жертв», а методология честно перечисляет ограничения (ACLED-покрытие, лаг верификации, возможные ошибки ИИ-дайджестов).

Отличие от Cassandra Index: WarMonit строит **описательную интенсивность по странам** (события → скор), а не многофакторную диагностическую вероятность эскалации по критериям. Их сильная сторона — плотность повседневного контента (карта, сводка, отвечалки), слабая — отсутствие аудиторской истории и глубокого методологического ядра.

## 4. Целевая аудитория

- **Квази-новостная массовая аудитория** — люди, которые гуглят «WW3 probability», «DEFCON level today», «how many wars» и «безопасно ли ехать в Дубай»; каждая такая тема отдельная answer-страница
- **Путешественники / экспаты** — перспективные travel-safety страницы (США/Британия/Канада 1–4 из-за частых战争的 мер, сня privileges hourly).
- **Journalists / researchers / publishers** — press-коннект с CC BY 4.0 на свои числа, embed-бейджи (iframe/SVG/Markdown) и «custom numbers on request» — прямой визуал для цитируёмости (та же некоторые идея, что у нас — freemium data).
- **Аналитики/команды** (Pro + API): хедж-фонды, рынок страхования, трейдеры на нефть/оборону.
- Free должно конвертить в Pro за счёт лимитов (3/10 вопросов аналитику, 5 в wire, 30 снапшот архива).

## 5. Методология

- **Country Instability Index (CII)**: композит 0–100 по стране — события ACLED, взвешенные по типу и смертности, + сигналы безопасности и информации, три компонента (unrest / security / composite); определяет «raitинг риска эскалации». Обновляется каждые минуты/часы.
- **Global threat level 0–10**: присваивается утром в 06:00 UTC из утреннего брифинга + счётчиков событий + военной активности; не публикуется метод, впрямую связывается с брифингом и хэшем дайджеста; полноценная публичная история с 10.03.2026.
- **AI-бифинг**: LLM работает по структурированной ленте проверенных событий за 24 ч (не «из памяти модели»); каждая сводка перечисляет источники; архив навсегда — «past assessments can be verified».
- **Явное позиционирование**: descriptive, not predictive; no WW3-percentage (отказ публиковать вероятность), на Pro — probabilistic scenarios «with drivers, indicators, history and a track record».
- **Честные оговорки**: описывает различия ACLED/UCDP, признаёт недосчёт в медиа-тёмных регионах.

## 6. Список источников

Поетод методологии страница перечисляет: **ACLED** (geo-coded события), **UCDP** (Уппсала), **GDELT** (10 000+ news-источников, анализ тона), **OSINT + официальные отчёты** (например МАГАТЭ по ядру), **рынки/монитуринг**: нефть/энергия, AIS-движение судов, военные полёты, HAPI/HDX (гуманитарные наборы). Третья-сторонние данные остаются под их лицензиями; свои числа — CC BY 4.0.

## 10. Тренды (что движет продуктом)

1. **Answer-page SEO** — каждая актуальная тема превращается в отдельную URL (WW3, DEFCON, как SAFE ли ехать в Х, country page для каждого фактора). Интересная ведомость для ведения статей.
2. **AI-об.summarization везде** — сводака писать LLM, и там трек-рекорд предсказаний объявлен.
3. **Privacy/прозрачность** — open-source AGPL-3.0 заявлен, CC BY 4.0 на свои данные, публичные CSV — явная попытка стать цитируемый стандартом, как GPR/ACLED.
4. **Расширяемость вертикалей**: конфликт→tech (tech.warmonit.com); вероятно следующий шаг — рынки/энергия/путешествия. Многие платежи / monetize подобно Cassandra Index (CC BY + Pro + API).

## 11. Стратегия развития

Диагноз по наблюдаемым признакам:
- Пирламент "answer engine + map + email": быстрая SEO-захват высоко-интент запросов (WW3, DEFCON, fainters questions), бесплатные числа (CC BY) → цитируемость/хэш читателей → Proboats подписка + API для компаний.
- Продукт активно растит поверхность (языки, app, travel, PDF-owej report, API-лимиты) с интервалом ~1 неделю.
- Родственны CutStaff.io указывает на долгосрочную модель: WarMonit как маркетинговый витрин и lead-gen для инженерных контрактов — это важно понимать конкурентно.

## 12. Ключевые клиенты

**Не раскрыты.** Прямых кейсов (маркировка «используют X») на сайте нет. Целевая аудитория Pro торгуется/оффер «для команд», «для журналистов», «для исследователей». BAS zoals… предупреждение: нет ни одного именования клиента — сигнал старта B2B-бизнеса, а не зрелой воронки.

- Стратегических партнёрств / проектных интеграций не обнаружено.

## 15. Прямое сопоставление с Cassandra Index

| | **Cassandra Index** | **WarMonit** |
|---|---|---|
| Возраст | ~2.5 года истории данных (08-02 →), пересчитанная методология 3.0 | 7.5 месяцев (домен 02.03.2026) |
| Ядро | 46 критериев, 9 драйверов, корroboration, инерция, калибровка на 10 якорях, k=1.95 | Композит по событиям ACLED + штраф peTaл | 
| Позиционирование | «не предсказывает войну, измеряет риск по критериям, методology audit-able» | «ситуативная осведомлённость: карта + сводка; описательная, не прогностическая» |
| Монетизация | нет (плановая не ADR) | Pro €9/€79 + API €49/€549 через Creem |
| Открытость | лицензии Apache/CC BY по слоям, git, публичный контракт API v1 | заявлен AGPL (репозиторий не найден), свои числа CC BY 4.0, CSV/json |
| Мультиязычность | RU-только | 12–16 языков |
| Публичные данные | data/public/** с JSON Schema, changelog, validation (GPR/ACLED/КрissWatch), forecast-ledger | threat-level.json/csv + cii.csv, embed-badges |
| Внешняя сверка | backtest vs GPR/ACLED/CrisisWatch (ADR 0063) | нет независимой валидации, «track record» только на Pro |
| Команда | продукто-набор+ редактор | 1 человек |

**Где WarMonit сильнее**: скорость выхода, поглощение внимания (карта/вид/бифингов), мультиязык, бесплатный API-сырья для прессы (embed), коммерческий серbis уже живой.
**Где Cassandra Index сильнее**: методологическая глубина и аудит-след, внешняя сверка, сл>About продуктовая дисциплина (ADRs, тесты, 769 тестов, JSON-схемы), передовой предиктивный слой (Precursor, форвард-якоря, реестр прогнозов).

## 16. Выявленные уязвимости WarMonit

1. Легальность коммерческого использования ACLED (у них лицензия ограничивает коммерческое применение — на Pro/API это питаются деньги).
2. AGPL-3.0 заявлен, но открытого репо не найдено — риск репутационного расхождения.
3. Метод уровня 0–10 не открыт (только описание «из брифинга и счётчиков») — несопоставим по стандарту с опубликованными весами ADR 0062.
4. 0 подтверждённых внешних пользователей/отзывов/клиентов — реальная масс-аудитория не доказана.
5. Проверка карты в триал без напоминания о списании — тонкий этичный spot, но законно с explicit согласием.

## 17. SWOT-анализ WarMonit

### Strengths (сильные стороны)
- **Скорость и широта продукта**: живая карта + дайджест + отвечалки запущены и обновляются непрерывно; 12–16 языков, Android-приложение — покрытие внимания больше, чем у любого «медленного» индекса.
- **Монетизация уже работает**: Pro €9/€79 и Pro+API €49/€549 через Creem (MoR) — без собственных платёжных сложностей; API-лимиты продаются как готовый B2B-продукт.
- **SEO-дисциплина**: answer-страницы под высоко-интентные запросы (WW3, DEFCON, «сколько войн», travel-safety по ~20 стран) — дешёвый органический трафик; llms.txt и Content-Signal в robots.txt — осознанная GEO-оптимизация под ИИ-поиск.
- **Скорость реакции автора**: одно лицо, нет согласований — продукт итерируется быстрее корпоративного темпа.

### Weaknesses (слабые стороны)
- **Методологическая толщина**: уровень 0–10 и CII описаны абстрактно («взвешено по типу и смертности»), без весов, порогов, якорей, калибровки и аудиторского следа; невозможна независимая проверка числа.
- **Никакой внешней валидации**: нет сверки с GPR/ACLED-агрегатами/CrisisWatch, нет независимых отзывов и публикации трек-рекорда (он закрыт в Pro).
- **Bus factor = 1** (solo, owner-dependency): болезнь/время автора = стоп продукта; AGPL-3.0 заявлен, но открытого репо не найдено — расхождение заявки и факта.
- **Легальная неопределённость входа**: лицензии ACLED/UCDP ограничивают коммерческое использование — Pro/API-модель построена на данных, чья коммерческая лицензия не подтверждена; в Terms лицензий источников не раскрываются.
- **Нет редакторского слоя**: AI-суммаризация без редактора — риск точности; оговорка «AI может ошибаться» есть, но это слабая защита доверия.

### Opportunities (возможности)
- Цитируемый стандарт по умолчанию: CC BY-данные + embed-бейджи могут принести медиа-продукт бесплатно.
- Pro-«forecasting AI» с вероятностями и track record — если сумеет как-то показать долг, то это огромная уникальная реализация аккуратного прогнозирования.
- Вертикали (tech, travel-safety, возможно energy/markets) — превращение в «платформу мониторинга», а не single-website.
- API для трейдеров/риск-менеджеров в период геополитической волатильности — высокий willingness-to-pay.

### Threats (угрозы)
- Лицензионное: ACLED sограничивает коммерческое использование; odin C&D может обрушить Pro/API-модель.
- Конкуренты уровня established (GPR, ACLED-собственный сайт, CrisisWatch, GEAB) просто забирают trust-аудиторию.
- Один человекames + быстрый AI-трафик волатильность: изменения в выдаче Google или GDELT могут разом нарушить SEO-вес.
- Низкое доверие аналитиков к «AI-предсказаниям»: любой замеченный перекос модели подрывает Pro-продажи вероятностей.

## 18. Конкурентное преимущество WarMonit (и как на него ответить)

WarMonit и Cassandra Index — не прямые продукты-двойники, но конкурируют за один ресурс: читателя, который хочет численную оценку мирового риска. Пять реальных граней преимущества:

| Компонент | Что у WarMonit | Что делает Cassandra Index | Что нужно, чтобы нейтрализовать |
|---|---|---|---|
| Осведомлённость (карта + дайджест) | Живая WebGL-карта со слоями, ежедневный email | Секции на сайте, но карты-сводки нет | Не конкурировать в «news-фиде», а подчёркивать диагностическое отличие |
| Мультиязычность | 12–16 языков автоматически | RU-только | Cassandra осознанно RU-only: глобальный multi-язык — расширение, пока не обязательное; дифференциация не в языках |
| Монетизация | Живает уже сейчас: Pro + API через Creem | Нет (план не зафиксирован в ADR) | Бенчмарк готов: Creem-модель рабочая и при соло-команде; если запускать — на своих, легально чистых данных, а не на ACLED |
| Публичность данных | CSV/JSON + embeds + CC BY | data/public/** с JSON Schema (уже глубже машины) | Сделать SVG/iframe badge на индекс — у нас этого слоя пока нет |
| Прогнозный слой | Pro-only вероятности без публичного track record | Precursor + форвард-якоря + forecast-ledger + validation.json — всё публично | Главный клин: **аудируемый прогноз против непроверяемых вероятностей** |

Вывод: WarMonit выигрывает по **скорости и охвату**, Cassandra Index может выиграть по **доверию**: проверяемость, внешняя валидация, открытая методология и публичный forecaster-ledger.

## 19. Уникальное торговое предложение (УТП)

**УТП WarMonit (как его видит рынок):**
> «Ты знаешь, где сейчас война — карта, число и письмо каждое утро, свободно на 12 языках, без регистрации».

Для посетителей это самая сильная формулировка: простой результат (карта + 5 пунктов в письме), мгновенная отдача, ноль барьеров. Для аналитика доступ: «каждая цифра несёт свой источник», «брифинг из структурированной ленты, не из памяти модели».

**УТП Cassandra Index против этого (противоположное позиционирование):**
> «Методологически проверяемый индекс риска: 46 критериев, калибровка на 10 исторических якорях, внешняя сверка с GPR/ACLED, публичный журнал прогнозов — числа, за которые отвечает расчёт, а не модель».

Это похоже на стиль «Cassandra Index» по духу, но зеркально по дифференциатору:
**WarMonit надёжнее ответит на вопрос «что происходит?», Cassandra — на вопрос «почему так считается?» и «кто от этого сообщал точнее?»**. Их аудитория — «любопытный массовый трафик» (SEO) и «prosumer» (Pro-подписчики), наша — «методологическая аудитория и журналистика» (research-oriented). Важно учитывать, что публичный «журнал прогнозов» (forecast-ledger с якорями) — единственный элемент, который соло-скрипту повторить сравнительно трудно: он требует истории честных зафиксированных ожиданий до событий.

### Ключевое уточнение позиционирования Cassandra Index (2026-10-24)

Канонический вопрос, на который Cassandra Index обязана отвечать:

> **«Куда и как движется глобальный конфликт — в мире и в регионах?»**

Это меняет расстановку сил по сравнению с WarMonit и задаёт три измерения ответа:

| Измерение | Что отвечает | Что уже есть у Cassandra | Пробел сейчас |
|---|---|---|---|
| **Куда** (направление) | Растёт или снижается риск, где ускоряется | Дельта недели (global delta), скорость региональных дельт, trend/на 12 недель, Precursor Risk как сигнальный слой Д9, форвард-якоря + forecast-ledger | Сравнение направлений **между регионами** не сведено в один экран: rankedRegions сортирует по \|Δ\|, но нет ответа «какие регионы ускорились сильнее всех за N недель» |
| **Как** (механизм) | Через какие драйверы и критерии это происходит | driver_breakdown + waterfall (§ ADR 0062), top-критерии, what_would_change, regionalSignals (атрибуция критериев регионам) | Развёртка отвечает «как изменился индекс», но не «как связываются воедино события → драйвер → регион» публичной формы |
| **Где** (пространство) | Региональная декомпозиция мирового риска | 12 регионов v2, слепые регионы честно помечены background, regional delta от прошлого фона (ADR 0038) | Нет карты/пространственного слоя — единственный компонент answer-запроса «куда», который у WarMonit готов, а у нас нет |

Сопоставление с УТП WarMonit: их продукт отвечает на вопрос «где сейчас идёт война» (материал: карта событий), но **не** «куда движется» — их уровень 0–10 публикует состояние, а тренд состоит только графом на одной странице; региональные дельты как концепт там отсутствуют вообще (CII — статичный скор страны на день). У Cassandra направленность (скорость), механизм (драйверная развёртка) и регионы (v2-таксономия + атрибуция) — это ровно «куда и как», чего у WarMonit нет во всей его поверхности.

Уточнённая формулировка УТП Cassandra Index (заменяет только вторую половину § 19 выше):

> **«Cassandra Index — не «есть ли войны», а «куда движется конфликт»: недельная динамика глобального риска, его разбор по 9 драйверам и развёртка по 12 регионам, публичный журнал прогнозов на каждый шаг — проверяемая траектория, а не снимок ньюс-фильма»**.

## 20. Key Takeaways для Cassandra Index

0. **Позиционный канон теперь зафиксирован**: Cassandra отвечает на вопрос «**куда и как движется глобальный конфликт — в мире и в регионах**» (§ 19.1). WarMonit остаётся «где происходят события» (карта + сводка); у нас — направление (дельты/тренд/Precursor), механизм (драйверная развёртка) и пространство (12 регионов). Пробелы, вытекающие из канона: региональный «portfolio-экран» направлений и компактная публичная форма «события → драйвер → регион».


1. **Монеточный бенчмарк готов**: €9/мес / €49 API через Creem (MoR) — готовая образцовая модель без юрлица-своего в ЕС, которую можно скопировать при необходимости, не создавая мерчант.
2. **Embed-бейджи и CC BY — самое дешёвое оружие дистрибуции**: у WarMonit это press-страница с iframe/SVG/markdown-бейджами; для Cassandra сделать SVG/iframe-бейдж на индекс — дёшево и усиливает reuse.
3. **Answer-page SEO — стратегия WarMonit, где он выигрывает** по охвату внимания: у нас это соответствует секции «как читать», ответникам, и blog/ — стоит расширять через высоко-интент вопросы («скільки военных конфликтов», «DEFCON», «ядерная опасность»).
4. **Их уязвимость — наша возможность**: отсутствие публичного метода уровня 0–10 и внешней сверки — то, что у нас уже закрыто (методология 3.0, validation.json, forecast-ledger). Дифференцировать по «аудируемой методологии».
5. **Легальность ACLED-коммерциализации** — таймер тикает и для их Pro-модели; при выборе источников для публичного слоя проверять лицензии до монетизации.
