# Бриф для второго кодировщика (одна страница)

**Что это.** Просьба независимо разметить сигналы двух недель по 46 критериям. Нужна не
оценка проекта и не мнение о методе, а значения по правилам. Ваша разметка будет
сравнена с моей; расхождение — не ошибка, а данные, которые войдут в статью.

**Что не нужно.** Читать мою разметку, обсуждать её со мной до сдачи, стараться
«угадать» моё значение. Лист, который вы получите, специально очищен: в нём нет ни
одного моего значения и нет подсказки, какой источник к какому критерию я отнёс.

## Что вы получите

Два файла: `coding-2026-09-20.json` и `coding-2026-10-18.json`. В каждом:

- `definitions` — 46 критериев: драйвер, тип шкалы (`count` / `ordinal` / `binary`),
  направление (`esc` — эскалация, `deesc` — деэскалация), название и описание сигнала;
- `sources` — корпус недели: id, заголовок, домен, адрес, дата, тип, кластер;
- `values` — то, что нужно заполнить: `"D1.1": null` → поставить число 0…1 или
  оставить `null`;
- `notes` — необязательное поле: можно добавить строку «почему» для спорного решения.

## Правила разметки

1. **Окно недели.** События с датой публикации в пределах недели: для `2026-09-20` —
   с 14 по 20 сентября 2026; для `2026-10-18` — с 12 по 18 октября 2026.
2. **«Покрыт»** = в окне есть источник, подтверждающий сигнал. Нет источника —
   `null`. Покрытие не дотягивается: оценка по памяти или «в мире же известно» запрещена.
   Пустая клетка — это честный результат, а не недоработка.
3. **Ordinal-шкала:** 0 / 0,33 / 0,67 / 1. **Binary:** 0 или 1.
4. **Счётные критерии:** вес события 0,2 / 0,5 / 1 / 2; сумма делится на 5 и
   ограничивается единицей. Пример: три события веса 1 → 3/5 = 0,6.
5. **Деэскалация** (`deesc`) кодируется так же: 0 — деэскалации нет, 1 — выраженная.
6. **Перенос из прошлой недели** допустим только для критериев Д2 (ядерная сфера) и
   должен быть помечен в `notes`; для остальных критериев это ошибка.
7. **Источники.** Пользуйтесь корпусом недели; если для критерия в корпусе ничего нет,
   но вы нашли источник сами — можно, добавив адрес в `notes`. Приоритет — источник,
   который прямо называет событие, а не пересказ.

## Сколько это займёт

Около 4–6 часов на две недели, лучше двумя сессиями (по неделе за раз). Спешить не
нужно: срок согласуем, ориентир — две недели с момента получения файлов.

## Как сдать

1. Заполните `values` в обоих файлах, не меняя структуру и не удаляя критерии.
2. Укажите себя в поле `coder` (имя или псевдоним — как хотите, чтобы вас назвали в статье).
3. Пришлите оба файла обратно одним сообщением.

## Что будет дальше

Считаю согласие: κ по покрытию (совпало ли, что критерий вообще покрыт) и взвешенную κ
по значениям, отдельно по каждому драйверу. Затем спорные клетки разбираются — с
возможностью вашего возражения; в статье указывается ваша роль и то, что разметка была
независимой. Если расхождение изменит значения, неделя будет пересчитана и это
зафиксируется в журнале аудита.

## Чего в этом не будет

Оплаты (проект без финансирования), соавторства (если сами не захотите иначе) и
публикации ваших персональных данных: в статье — только роль и, при желании, имя.
