## Порядок

1. Заполнить сведения об авторе и названия (рус./англ.).
2. Написать разделы по подсказкам: подсказка курсивом — это «что должно быть», а не текст.
3. Вставить таблицы из Приложений А и Б (данные в файле уже стоят), при желании заменить на свои.
4. Собрать русский список литературы, привести References к образцам журнала (курсив названий, EDN).
5. Сделать график по `chart-data.csv` в чёрно-белой графике, сохранить исходник .xlsx.
6. Заполнить Приложение Г после двойного кодирования.
7. Пройти контрольный список в конце документа и отправить файл через форму на politstudies.ru
   или на `new-authors-politstudies@mail.ru`.

## Чего в документе намеренно нет

- Готового текста статьи: журнал прямо запрещает написание текста инструментами ИИ,
  а рукопись проверяется на уникальность.
- Русскоязычных ссылок: их нельзя придумывать, а проверить каждую без доступа к eLIBRARY
  нельзя — это делается автором.
- Цветной графики: журнал принимает только чёрно-белую.
