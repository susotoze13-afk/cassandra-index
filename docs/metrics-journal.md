# Cassandra Index — Журнал метрик

**Назначение:** аудиторский след продуктовых метрик для проверки гипотез ADR 0033
(«доверие и действия»). Не аналитика ради аналитики: каждая строка — цифра,
по которой считается дельта после выката правок.

**Источник данных:** Cloudflare Web Analytics (beacon `js/analytics.js`, только
после согласия пользователя). API клиента нет — срез снимается **вручную** раз в
неделю и заносится строкой. Это не блокирует правки (grilling 2026-10-17, Q13).

**Целевые метрики (ADR 0033):**

1. **Доля переходов по share-ссылке** — из `js/share.js` (карточка несёт уровень и
   дельту недели). Показывает, рекомендуют ли индекс дальше.
2. **Брендовые запросы** («индекс касандры», «cassindex») — приход по прямому
   знанию бренда, признак регулярного использования.
3. **Регулярность визита** — доля вернувшихся на неделе (если CF Analytics даёт
   срез; иначе — качественно).

**Окно оценки:** 12 недель после выката фазы 1 ADR 0033.

## Правила ведения

- Срез — раз в неделю, одна строка; пропуск недели не восстанавливается задним
  числом (честность истории важнее полноты рядов).
- Дельту считаем от baseline-строки выше, а не от предыдущей недели, — цель стоит
  на горизонте 12 недель.
- Если метрика недоступна в CF Analytics — честно пишем «н/д» и причину, а не
  выдумываем число (конвенция проекта: отсутствие возможности — не повод
  искажать).
