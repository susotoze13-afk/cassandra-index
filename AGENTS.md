# Cassandra Index

Публичный еженедельный сервис, сообщающий текущий уровень и направление риска
глобального конфликта на основе открытых данных. Продукт не предсказывает дату
начала войны и не представляет индекс как вероятность войны.
Спецификация — `PRD_Casandra_Index.md` (v1.3).

## Команды

Тесты: `node --test` (без аргументов — прогон всех `tests/*.test.js`; форма
`node --test tests/` падает на Windows/Node 24). Один файл: `node --test tests/<имя>.test.js`.
Сайт — статика без сборки: открыть `index.html` (работает с `file://`).

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
